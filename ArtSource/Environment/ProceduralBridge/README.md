# 程序化木桥构件

2026-09-24：用于独立岛屿研究室，尚未接入主游戏。用户要求随机岛屿沿用主岛质感，同时提高木桥细节；本次沿用主岛地表、短草、岸石、水草与松土，另外制作木桥构件。当前采用版本为 `20260924/`，开发侧检查完成，最终风格仍待用户体验确认。

- 图片工具制作单体木柱参考，Tripo P2 图转模型制作桥柱（木纹、柱帽、榫孔、绳结）；实际 **120 积分**。任务、精确版本、参数及完整图片提示词见 `20260924/generation-record.json`，服务脱敏回执及原模在 `20260924/raw/`。
- Blender 5.2.2 LTS 将桥柱等比归一为 0.9 米高，底面居中，保留原始拓扑与 4096² 颜色贴图。实际 1847 三角形，服务请求值为 1800，不能当作实际面数。
- 木板、扶手和承重梁由 Blender 精确制作，三段倒角，分别 188 三角形；共用新绘制的 1024² 木纹。它们不是 Tripo 输出。脚本以长轴展开纹理；Godot 按桥宽／跨度拼装，短板留缝、栏杆分开间，底部配置承重梁、桥桩和斜撑。
- 每件一个网格、一个材质，粗糙哑光，无骨骼／动画。桥柱不减面，不做云端分割、重拓扑或重贴图：当前单体拓扑、接地与纹理满足重复构件用途。关闭引擎自动 LOD，防止少量细节被自动削掉。

在仓库根运行 `blender --background --python-exit-code 1 --python ArtSource/Environment/ProceduralBridge/20260924/prepare.py` 可重建：覆盖本版本的木纹、`bridge_modules.blend`、`audit.json` 和 `Game/art/environment/procedural_bridge/{post,plank,rail,beam}.glb`；不覆盖 Tripo 原模。随后执行 `scripts/godot.ps1 -Action Import`。脚本会在空场景重导入导出文件，核对 UV、纹理、有限坐标和三角数，失败以非零状态结束。

`Game/scenes/procedural_lab/island_view.gd` 是拼装入口。验证使用 `tests/procedural_lab_scene_test.gd`，包括种子重建、近远镜头和桥梁／接头相反侧近看。布局仍由 `tests/procedural_island_test.gd` 检查桥口承托及通路净空。原始源、导出与 Godot 实景是三个不同验证阶段；自动化通过不代表用户已批准风格。

制作节点 `20260924-程序化岛屿质感与木桥构件`：参考→原模在本目录，整理源与审计在日期目录；实景截图与离线演示存于本地 `制作留档/05_开发录屏/028_20260924_程序化岛屿质感与木桥构件/`。演示只展示研究场景，不是主游戏玩法或实时性能测量；制作贡献为对话助手协调与程序生成、图片工具出参考、Tripo 出木柱、Blender 出精确构件、Godot 拼装与渲染。
