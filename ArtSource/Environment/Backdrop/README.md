# 远山与河岸背景

`river-distance.png` 由内置 image_gen 单独生成，固定 `farm-gongbi-v1.png` 为风格/地理参考；原图包含多层淡青山脉、薄雾、远岸树与极小民居，不包含近景庭院、UI或作物。图像工具未返回具体模型版本、种子及费用。

Godot 使用192三角的完整环形曲面，半径65m，上沿20m、下沿-50m。镜像采样让两个接缝使用相同边界像素，纹理clamp防止mipmap在边缘回卷出细线。近处180m水面在XZ半径22–35m淡出接远水色；普通不透明大平面会挡住俯瞰中的背景，已实测修正。

`atmosphere_tint` 默认白，供3.4夜间降低亮度和转冷；不能因unshaded而保持白昼亮度。远岸是视觉背景，不承诺航行、抵达或建筑交互。合法镜头极限与额外背面已有真实图；部分俯瞰近景仅见远水雾而不见山峰，这是视角结果，不使用随镜头贴脸的整场截图。
