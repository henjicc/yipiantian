# 远山与河岸背景

`river-distance.png` 由内置 image_gen 单独生成，固定 `farm-gongbi-v1.png` 为风格/地理参考；原图包含多层淡青山脉、薄雾、远岸树与极小民居，不包含近景庭院、UI或作物。图像工具未返回具体模型版本、种子及费用。

Godot 使用192三角的完整环形曲面承载，半径65m，上沿20m、下沿-50m。5.3 对照发现直接圆柱 UV 把村柳岸压到近水下面；视觉修正现保持横向世界方位的镜像采样，纵向改为每个观察方位的远竖平面投影，避免弯碗形岸线。纹理 clamp 防止边缘回卷，水部下裙渐混为远水色，近处180m水面在 XZ 半径13–23m淡出，实际图中恢复山→村柳岸→远水层次。方法、否决中间结果和实测见 [水面与远景修正交接](../../../docs/task/首个可发布版本/handoffs/3.4-visual-refinement-handoff.md)。

`atmosphere_tint` 默认白，供3.4夜间降低亮度和转冷；不能因unshaded而保持白昼亮度。远岸是2D绘画背景，不承诺航行、抵达、山体近景视差或建筑交互。合法镜头极限已有真实图；部分俯瞰近景仅见水而不见山峰，这是视角结果。背景仅专用远山河岸绘画，主岛、田块、建筑与船桥均为真实3D，不使用整张主界面截图冒充运行场景。图像最底部低对比水色另由3.4以很低权重静止采样为近水淡彩底，不滚动笔触或伪称真实物体反射。
