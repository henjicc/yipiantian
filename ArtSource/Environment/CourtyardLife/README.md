默认景深170%、雾28%。`courtyard_haze.gdshaderinc`以主岛XZ清晰椭圆为基准，外围左右及后方逐渐增雾，主田始终保持清晰；共享函数作用于远岛、植被、水和绘景水面，镜头放大不重新起雾。相机近处框景显式豁免。雾色上传需由sRGB转线性，否则夜晚被错误抬亮。保留水面的 `depth_draw_always`，避免MSAA+景深下叶片边缘出现虚线黑边。

契约参考：[Godot空间着色器FOG和深度写入](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html)、[全局shader uniform](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/shading_language.html#global-uniforms)。统一世界雾是本项目美术方案，不是引擎物理雾保证。

### 鸡的定头与步相：20260919-hen-hold-thrust

用户反馈旧版鸡头怪异。根因是腿按路程推进，头按固定2.15Hz正弦摆动，身体又使用时间脉冲；三个节奏会分离，瞬时速度还会反复缩放腿部幅度。现由真实移动距离统一驱动鸡的换脚、速度脉冲和头部前伸；原Tripo骨架与贴图不变，无生成费用。

研究依据：鸟类步行头部有快速前伸与相对环境稳定两个阶段，见[Necker 2007](https://pubmed.ncbi.nlm.nih.gov/17987297/)；[Muir与Chu 2002雏鸡实验](https://journals.physiology.org/doi/full/10.1152/jn.2002.88.1.117)记录每个完整左右腿步态周期两次头部周期；[Muir与Gowri 2005](https://pubmed.ncbi.nlm.nih.gov/16093327/)观察缩短步幅伴随更频繁脚步和较小头部位移。这些不提供本项目成年母鸡的唯一正确频率，下面数值是游戏调校。

- 完整左右腿步幅由.22m缩至.16m，按两只鸡各自尺度换算；每半步一个头部周期。沿用最高.23m/s，不单独给头提速。
- 每步前26%的路程快速前伸，随后用局部后移抵消身体前进，移除鸡走路时的正弦上下晃动与闲置扭头。换脚处短暂减速至目标速度的24%，保持非零防止按路程推进的相位停死。
- 步行颈链只求解躯颈骨，头部保持初始全局朝向，不再靠头骨俯仰追嘴尖；啄食、理羽与鸭鹅动作沿用原路径。移动时腿部幅度保持完整，只在起停时淡变，缩小鸡的步相与脚部位移同时按实例比例换算。
- 定向检查 `tests/hen_gait_test.gd`：直接运行真实鸡骨架，以.10/.23m/s及.88/1两种尺度量测蒙皮嘴尖，定头阶段水平速度约为身体27–28%，前伸约4倍；停止后步相不继续走。目标是明显稳定而非宣称绝对锁定或生物测量复刻。新测试通过，开发者审美结论不替代用户实看。
