## 实机结论与复用

独立场景 `Game/scenes/style_sample/style_sample.tscn`，Godot 4.7.2 / Forward+，1920×1080 真渲染，全景／正背／青菜高低／轻景深／15°微调／夜景均实际查看。画面保留颜色笔触及圆瓦轮廓；正式环境仍需 3.2 补侧开间、廊台、院落植被、石桥木船与远山，不能把样片体块当成品。

- 样片采用线性色调映射、环境光 .40、日主光 .80／`fff8ea`、雾 .0015；最初 FILMIC＋高暖环境光把灰瓦和叶色洗浅，已修正。该组是样片起点，不锁死后续昼夜参数。
- 民居低档在全景保持屋顶大轮廓和格窗身份；房屋特写使用高档，近处窗棂不宜强制低档。两档尺寸差异 <0.3%。Godot 导入自动 LOD 保持开启，本样片另显式比较高低同源资源；焦点身份与迟滞控制交 3.5。
- 同场成熟青菜高档 2988 三角形不改。样片低档 `Game/scenes/style_sample/greens_sample_low.glb` 为 **1494** 三角形：先合并重导入 UV 接缝的重合顶点，减面 50%，再清理自定义法线并平滑。此前直接降至 1015 的版本出现叶缘碎面，已弃用。3.1 可复用最终低档而无需再次付费。
- 8 m 聚焦下清晰带约 5.2–9.7 m，近过渡 2 m、远过渡 5 m、强度 .045；整田叶片清晰，前后景温和虚化。低画质／景深关闭仍需用 LOD 控制成本。[Godot 4.7 官方景深属性](https://docs.godotengine.org/en/4.7/classes/class_cameraattributespractical.html)。

本地完整截图、对照与制作副本在 `制作留档/03_处理与验证/03_民居风格样片/`；阶段影片在 `制作留档/05_开发录屏/011_20260917_民居与青菜风格样片/`。这些是制作证据，不是工程依赖，也不是实时性能证明。

## 可重复入口与下载事实

用已配置 Blender 后台运行 `prepare_house.py` 会覆盖本整理源及导出物，人工编辑后勿盲目重跑。脚本也生成样片青菜低档，但不改成熟青菜正式源。Godot 使用根 `scripts/godot.ps1`，独立场景支持 `--capture-dir=<绝对目录>` 输出九帧；中键微调、空格比较高低、Esc 退出，不含农事或存档。

生成任务到达 success 后一度 CLI `fetch failed`、PowerShell／curl TLS EOF；本地 DNS 返回 198.18.* 假 IP。用户切全局代理期间一次保留主机证书校验的局部解析下载成功，随后**普通 CLI 同 ID 下载也成功**；不能单独归因局部解析。无重新生成、无新增费用、未改系统代理或禁用证书校验。遇到同类问题先确认任务状态并重取同一 ID，不能把下载失败误当生成失败。
