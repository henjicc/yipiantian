## 整理与运行

`prepare.py`使用Blender5.2.2，统一10米跨度、底部原点和Godot前向；高档保留原几何和4K色图。低档在副本焊合接缝、保留面角UV、减至约24000三角后清理退化元素。竹林低档曾因无效环被导出器静默删面，现导出前清理并重新导入核验一致性。原模型不可改写，可编辑源为`20260918/{名称}.blend`，审计为`{名称}-audit.json`。

重建：`blender --background --python-exit-code 1 --python ArtSource/Environment/Islets/prepare.py -- willow bamboo cottage`。各档一个网格、一个材质、无零面积面，重导入核对面数和贴图。高档开放边1／5／5、低档1／7／5，不能宣称全部水密；可见轮廓与接触按实景检查，不盲目补洞。正式资源`Game/art/environment/islets/`禁用额外导入自动LOD。

首版五岛现已纳入[十岛群布局](../Archipelago/README.md)。用户要求统一世界尺寸：源资产均为10米跨度，场景scale=1；不再把远层实例缩至0.48，也不单独放大远岛。只调整位置和朝向，表观大小来自透视。标准画质按实际距离52进入低档、45恢复高档；低画质强制使用低档，切回标准立即重新判断。首版生成源与费用记录仍保留在本页。

水下部分在同一水位-0.27米裁除，避免远处真实水面过渡到绘景后露出岛底；近水位加湿色。距离雾同步昼夜雾色，降低远岛对比。[Godot4.7 FOG输出](https://docs.godotengine.org/en/4.7/tutorials/shaders/shader_reference/spatial_shader.html)。
