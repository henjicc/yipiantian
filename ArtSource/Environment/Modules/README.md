# Blender 精确院落模块

`../build_modules.py` 为可复现制作源，`courtyard_modules.blend` 保留独立对象；导出到 `Game/art/environment/modules/`。

不规则岛岸保持田块所在水平区域；五种倒角/平滑河石按自然组团布局；石桥由真实拱券拼接，桥下开放；侧屋有厚瓦、山墙、门窗木框，廊台有平台/台阶/柱脚/栏杆；入口草棚有立柱、撑杆、屋面杆与绑条；竹栏有节与横杆；田框内空不改变soil尺寸。

各对象独立GLB、米制，实际三角与重导入结果见 `asset-audit.json`。简单精确结构共用单档，Godot自动LOD保留；不为每级重生成。石桥拱券曾显得棱角过硬，已加3段35mm倒角；岸石统一平滑，尺寸/朝向/高度不按等距球体排列。Godot在原材质色上加低幅色层，依然保留桥石与木材分材质。

脚本会覆盖本目录整理源及模块导出；人工编辑后不要盲目重跑。无外部付费生成，几何由Blender实际创建，程序化组装归Godot贡献。
