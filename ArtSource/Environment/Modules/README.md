# Blender 精确院落模块

`../build_modules.py` 为可复现制作源，`courtyard_modules.blend` 保留独立对象；导出到 `Game/art/environment/modules/`。

不规则岛岸保持田块所在水平区域；五种倒角河石按自然组团布局，石顶收窄偏移、侧面保留大切面；石桥由加厚真实拱券、错缝桥台、双层石栏板及压顶构成，桥下开放；侧屋有厚瓦、山墙、门窗木框，廊台有平台/台阶/柱脚/栏杆；入口草棚有立柱、撑杆、屋面杆与绑条；竹栏有节与横杆；田框内空不改变soil尺寸。

各对象独立 GLB、米制，实际三角与重导入结果见 `asset-audit.json`。简单精确结构共用单档，Godot 自动 LOD 保留；不为每级重生成。2026-09-17 的格子与画面重构中，石桥为 15800 三角、5 材质；五种岸石各 184～216 三角。桥和岸石均经 Blender 5.2.2 独立重新导入，拓扑检查无非流形边或游离点、缩放已应用。岸石取消整块平滑法线，避免纵向放大后像圆桶；尺寸、朝向和高度不按等距球体排列。Godot 材质保留底色，增加低幅矿物色层、近水湿色和苔痕。

局部重出可在 Blender 参数分隔符后传 `--only stone_bridge stone_0`；仍重建完整源场景，仅导出并核验指定 GLB，保留其他资源与审计条目。修改前在 `.local/` 留存工作副本，正式源与导出物同时提交。

脚本会覆盖本目录整理源及模块导出；人工编辑后不要盲目重跑。无外部付费生成，几何由Blender实际创建，程序化组装归Godot贡献。
