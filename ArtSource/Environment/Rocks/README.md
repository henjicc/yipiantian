## 重建与运行

使用 Blender 5.2.2 LTS：`blender --background --python-exit-code 1 --python ArtSource/Environment/Rocks/20260917/prepare.py`，随后运行 `scripts/godot.ps1 -Action Import`。必须同时检查退出码、日志和 [资产审计](20260917/asset-audit.json)，不能仅凭 Blender 正常退出宣称脚本成功。

`prepare.py` 从不可变 `*/raw/model.glb` 重建；焊接、清理退化面、同源减面、平滑法线、统一底部原点。水平最长边约0.95米，高度分别适配为0.27／0.12／0.22／0.22／0.34米，以兼容既有岸石组合比例；这是纵向非等比整形，不声称保持生成比例。五份4K原贴图各缩为640方图，带16像素间隔排进2048²共用图集；原始4K贴图仍在 raw GLB。游戏网格共6200三角形，均单材质、单UV、零非流形边／孤点／零面积面，重导入一致。

输出 `river_stones.blend` 为五个独立网格（原点重叠，编辑时单独显隐），以及 `Game/art/environment/modules/stone_0..4.glb` 和 `river_stones_color.png`。Godot 自动提取的五份同内容贴图及其导入文件也是 GLB 依赖，保留；正式石头材质和田块合并网格使用共用图集。禁用这五件资源的导入自动LOD，使用已整理网格。旧 `build_modules.py` 的手工石头仅为历史来源，不再是现役生成入口，不能用其覆盖本批资源。

岸边沿用确定性组合，通过不同形态、旋转、尺寸和埋深打破重复；走路石板只选 flat／long，田块压边共用合并网格。图集在 `pigment.gdshader` 的石头专用分支降低饱和度、减轻苔色，保留原纹理起伏和浸水色；不改变桥和岛岸的材质策略。岸石继续参与真实岸线距离场，船附近保持避让。

## 验证与限制

实际检查源模型正背面、完整场景、东西岸、反向近景、田边／石板及夜间。完整场景219项、表面整合24项（146个岸石包围区域，船60秒摆动无重叠）、水岸11项、装饰取景12项通过。近景顺带发现并修复既有陶罐／篮子／石磨旋转体绕序反向的问题，补正面方向回归；生活细节27项通过。右侧竹子及石磨小幅外移后，装饰操作34项通过，槽位和存档身份未变。
