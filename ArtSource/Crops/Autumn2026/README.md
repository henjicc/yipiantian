## 来源与处理

1. 图片工具分别生成十种新菜参考、青菜与白萝卜图标，以及指针／水壶／收获工具，共十五张 RGBA 透明图。实际提示词与生成文件位置见 [image-records.json](image-records.json)，每张持久副本在 `<id>/reference.png`。十种新菜同一参考用于 Tripo 和 UI。旧青菜／白萝卜的模型未重生，新的图标不是其旧模型的原始参考。
2. 每种新菜单独图生模型，使用 Tripo H3.1 Ultra，服务回显 `model_version=v3.1-20260211`、`geometry_quality=detailed`、`face_limit=20000`、`smart_low_poly=false`；纹理 `v3.5-20260815`、`detailed`、`texture=true`、`pbr=false`、`delight=true`。种子 202609180～189。十次成功，每次 60 积分，共 600；余额变化已核验。任务映射见 [tasks.json](tasks.json)，每份 `raw/task.json` 保存精确回显和费用。图片生成不包含在 Tripo 积分内。
3. 每份 `<id>/raw/model.glb` 与预览不可变。Blender 5.2.2 LTS 通过 [prepare.py](prepare.py) 整理副本：保留源拓扑，不减面、不盲目焊点；设哑光材质、双面叶片、种植尺度，将根颈放到原点，根系埋土。每株横向不超过 0.4 米。成熟源保存为 `<id>/<id>.blend`，贴图打包在内。
4. 幼株复用同一成熟源，横向缩至 54%、高度 64%，根颈不动。幼芽由 Blender 生成闭合弯曲子叶／葱蒜带状幼叶。**幼株不是独立生成的幼年植株，幼芽不是 Tripo 生成；没有语义分割或骨骼绑定。** 当前三阶段有切换，并非连续植物学发育。
5. 导出到 `Game/art/crops/<id>/<id>_{sprout,young,mature}.glb`；成熟导出重新导入核对包围盒。计数、根颈和培土半径见 [asset-audit.json](asset-audit.json)。新增成熟模型约 1.8～2 万三角／株，导入 `meshes/generate_lods=false`，避免未经检查的薄叶简化；原两菜现有高低档保留。这是当前十种作物的质量选择，不是全局关闭 LOD，不声称已完成满田性能认证。
6. Godot 使用已有植物风动和根部沾土／培土，所有新增叶菜采用小幅根部约束风动。未引入粒子解算种植状态。十五张 UI 图片保留完整源，运行导入限制 256 像素；原生箭头按 64 逻辑像素随窗口缩放（48～170 物理像素），携带图标 48 逻辑像素，与箭头合成在不超过 256×256 的硬件光标内，保留透明通道。

重建：用固定 Blender 执行 `--background --python-exit-code 1 --python ArtSource/Crops/Autumn2026/prepare.py`，再用项目 Godot 导入入口处理资源；保留已提交的 `.import` LOD 设置。重建不能自动重新付费生成；只有原模不合格时才重新评估。

## 操作与状态

- 点击底部“播种”后在上方展开十二张蔬菜卡，不要求先选田或格。选择即拿起种子，滚轮循环换菜；悬停显示目标格，点击播种，成功后保持工具方便连续种植。
- 点击底部“工具”展开浇水／收获，按钮只拿起工具，点击土地才执行。进入游戏即显示自定义箭头，持物时在同一硬件光标内显示当前菜或工具透明图；工具与菜品共用上图下字卡片。右键、Esc、取消按钮放下并收起面板；放下种子后滚轮恢复阻尼缩放。
- UI 上、拖动中、镜头过渡中、自由视角或失焦不会误种；跨格按下／释放不种。空手点田仍可聚焦。
- 当前开发存档为 v4，目录 `user://farm-v4`，旧 `user://farm` 保留但不迁移，符合早期开发无需旧数据兼容的要求。来源与操作帮助一并更新。
