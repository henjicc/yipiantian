# 产品形态与平台行为

> 读取时机：改变窗口、焦点、生命周期或 Windows 桌面能力时；单纯文案和局部样式不触发。

## Windows 窗口版基线

- 当前运行单元为 `Game/` 中的 Godot Windows 窗口程序，已接入种植、现实时间生长、本地保存回访及轻量布置。界面围绕三维场景与照料操作组织，不套用网站导航、落地页或桌面效率工具布局。
- 只实现当前任务需要的窗口行为；焦点变化、最小化、恢复、窗口尺寸与 DPI 变化不得导致误操作或农场状态损坏。不假设游戏始终拥有焦点，不擅自抢焦点或注册全局快捷键。
- 失焦、鼠标离开或释放拖动时应有明确的工具取消 / 完成语义，避免恢复后继续浇水、拖拽或穿透 UI 操作地块。
- 正常关闭应退出游戏；“关闭到托盘”、开机启动与常驻后台需要对应产品需求，不默认加入。存档与异常退出恢复按模拟规则处理。
- 前后台、渲染暂停、模拟结算和声音的策略分别明确；暂停画面不等于冻结现实时间生长。休眠和恢复按 [farm-simulation.md](farm-simulation.md) 处理。
- 当前不承诺其他平台及全部 Windows 版本；实际构建目标与兼容范围在工程建立时核验记录。

- 可见的 `--dev-preview` 失焦时允许最高60fps（不超过用户更低的帧率上限），方便用户操作主屏同时观察副屏动画；最小化及普通非开发后台仍按15fps节流。渲染例外不改变静音与声音失焦策略。

## 独立桌面壁纸

- 多屏电脑同一时间只允许在一块屏幕上展示农场壁纸。当前以进入壁纸模式时游戏所在的显示器为目标，按该屏位置和尺寸挂接；其他屏幕保留原桌面，不跨屏拉伸或同时复制。被覆盖判断也只针对目标屏幕。需要换屏时先返回窗口模式，将游戏移到目标屏幕，再进入壁纸。
- 窗口版玩法与存档不依赖桌面嵌入。无边框、透明、置顶、点击穿透和桌面背景层嵌入是不同能力，不能用其中一项成功代替其他项验证。
- 用户已要求独立运行，当前以随包 `FarmDesktop.exe` 实现当前屏幕的观赏壁纸，不依赖其他壁纸软件。Windows 操作与农场逻辑隔离，宿主不读存档；仅壁纸模式常驻，正常退出仍结束游戏。点击未被其他窗口或桌面图标遮挡的门口农具可返回游戏并拿起工具，保留双击托盘返回、右键保存退出。仅壁纸挂接期间注册鼠标 Raw Input，通过桌面窗口与可访问角色筛选空白点击，再由游戏做农具表面命中；不吞鼠标事件、不收集键盘、不转发其他程序操作，不自动开机启动。
- 可见壁纸最高30fps、目标屏幕被覆盖或锁屏最高2fps；切换时短暂恢复正常消息处理速度。限帧不冻结生长，也不能代替资源占用实测。职责、构建、恢复约束和未验证边界见[桌面组件](../native/desktop/README.md)。
- 目前仅 Windows 10 本机基础切换通过，Windows 11、混合 DPI、Explorer 重启等按实际证据扩大承诺。验证不得擅自重启用户 Explorer 或干扰其他程序。用户使用电脑期间优先代码与构建检查，把托盘和随机交互留给用户反馈，不自动反复操作桌面。
- 平台 API 与版本行为不确定时按研究规则核验；不能将非公开或实验行为表述为官方长期兼容保证。
