# 产品形态与平台行为

> 读取时机：改变窗口、焦点、生命周期或 Windows 桌面能力时；单纯文案和局部样式不触发。

## Windows 窗口版基线

- 当前运行单元为 `Game/` 中的 Godot Windows 窗口程序，已接入种植、现实时间生长、本地保存回访及轻量布置。界面围绕三维场景与照料操作组织，不套用网站导航、落地页或桌面效率工具布局。
- 只实现当前任务需要的窗口行为；焦点变化、最小化、恢复、窗口尺寸与 DPI 变化不得导致误操作或农场状态损坏。不假设游戏始终拥有焦点，不擅自抢焦点或注册全局快捷键。
- 失焦、鼠标离开或释放拖动时应有明确的工具取消 / 完成语义，避免恢复后继续浇水、拖拽或穿透 UI 操作地块。
- 正常关闭应退出游戏；“关闭到托盘”、开机启动与常驻后台需要对应产品需求，不默认加入。存档与异常退出恢复按模拟规则处理。
- 前后台、渲染暂停、模拟结算和声音的策略分别明确；暂停画面不等于冻结现实时间生长。休眠和恢复按 [farm-simulation.md](farm-simulation.md) 处理。
- 游戏不请求屏幕常亮，服从用户的系统电源计划；连续渲染测量可由隔离测试进程临时保活，必须记录该覆盖，不能修改系统电源计划或用于证明自动熄屏行为。
- 当前不承诺其他平台及全部 Windows 版本；实际构建目标与兼容范围在工程建立时核验记录。

- 可见的 `--dev-preview` 失焦时允许最高60fps（不超过用户更低的帧率上限），方便用户操作主屏同时观察副屏动画；首次启动的短时画质测试只在前台暂时解除帧率限制和垂直同步，结束恢复；失焦样本无效，不能抢焦点补测。普通窗口仅失焦时按15fps节流；最小化时停止绘制并暂停场景更新。渲染例外不改变静音与声音失焦策略。

## 独立桌面壁纸

- 多屏电脑同一时间只允许在一块屏幕上展示农场壁纸。当前以进入壁纸模式时游戏所在的显示器为目标，按该屏位置和尺寸挂接；其他屏幕保留原桌面，不跨屏拉伸或同时复制。被覆盖判断也只针对目标屏幕。需要换屏时先返回窗口模式，将游戏移到目标屏幕，再进入壁纸。
- 窗口版玩法与存档不依赖桌面嵌入。无边框、透明、置顶、点击穿透和桌面背景层嵌入是不同能力，不能用其中一项成功代替其他项验证。
- 用户已要求独立运行，当前以随包 `FarmDesktop.exe` 实现当前屏幕的观赏壁纸，不依赖其他壁纸软件。Windows 操作与农场逻辑隔离，宿主不读存档；仅壁纸模式常驻，正常退出仍结束游戏。悬停未遮挡农具可高亮，点击后在壁纸原位操作，结束操作仍保持桌面挂接；托盘可主动返回窗口或退出。游玩和观赏必须始终保持游戏在桌面图标下方，禁止为原生输入或鼠标样式把游戏提到图标前面。壁纸用系统鼠标，手持物以不接收鼠标事件的小图标单独跟随；不得因为恢复物品提示而改变系统箭头或桌面层级。游玩只切换输入门禁。宿主在钩子外缓存桌面图标及文字的矩形，在钩子内按当前窗口与矩形排除图标、任务栏和其他应用；不再要求鼠标与上一采样点完全一致。只截取游玩中从农场空白区域开始的按钮和滚轮，捕获按下到释放避免桌面拖选；非游戏起始的拖动不转发。普通移动不拦截，不采集键盘文本，仅鼠标事件携带Shift/Ctrl/Alt状态。任务栏工作区由宿主通报给HUD避让。座椅或设置结束操作保留相机、工具与页面，再点击座椅继续。
- 观赏壁纸最高30fps，桌面游玩最高60fps；目标屏幕完全不可见、锁屏或熄屏时停止绘制并暂停场景更新。活动状态管理器统一控制，宿主管道与托盘仍响应；切换时恢复60fps消息处理。连续不可见5分钟后释放可快速重建的渲染缓冲与无活跃引用的场景缓存，恢复时先结算现实时间再绘制；不能用限帧、工作集裁剪或清空画面冒充资源达标。职责、构建、恢复约束和未验证边界见[桌面组件](../native/desktop/README.md)。
- 目前仅 Windows 10 本机基础切换通过，Windows 11、混合 DPI、Explorer 重启等按实际证据扩大承诺。验证不得擅自重启用户 Explorer 或干扰其他程序。用户使用电脑期间优先代码与构建检查，把托盘和随机交互留给用户反馈，不自动反复操作桌面。
- 平台 API 与版本行为不确定时按研究规则核验；不能将非公开或实验行为表述为官方长期兼容保证。

- 桌面图标枚举以 SysListView32 的 `LVM_GETITEMCOUNT` 为实际数量来源，不将 `IAccessible.get_accChildCount` 直接当作有效图标ID上界：本机已复现额外无效末项。读取前后核对真实数量，图标边界失败仍拒绝未知输入；输出状态变化和失败阶段，避免静默禁用整个桌面输入。
