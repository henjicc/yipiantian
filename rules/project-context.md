## 已确认基线与创意方向

- 用户于 2026-09-17 确认直接切换 Godot，不再做引擎对比实验。仍先制作 Windows 普通窗口版三维农场小游戏，正式桌面壁纸宿主后置。实现默认采用带类型标注的 GDScript，当前为 Forward+ / Vulkan；精确版本以 [.godot-version](../.godot-version) 为准，首个可发布版本计划已获用户授权自主实施，逐项由子代理执行并生成交接；进度与定稿边界见 [任务总览](../docs/task/首个可发布版本/00-任务总览.md)，尚未实现部分以各任务状态为准。
- 创意目标：与现实时间同步、可以照料和布置、会持续生长的微缩农场，强调轻松、低打扰的观察和操作体验。规则以此指导后续取舍，不把创意清单全部作为已批准功能。
- 最新视觉方向为架空中国古代田园：宋明江南民居与生活气质。用户已选定第二轮 01 图的观察距离、整体构图与感觉，主图保存在 [制作基准包](../docs/design-baseline/README.md)。随后明确要求更圆润简洁的卡通形体，反对摄影级蔬菜细节，现已确认 A 工笔淡彩全景与 A 淡彩青菜的风格和质感；固定参考、原始提示词与复用模板见 [风格基准 v1](../docs/design-baseline/style-guide.md)。B / C 等保留为历史探索，不再待选。主图负责构图和空间氛围，不再用其微小写实纹理否定后续风格修正。低多边形只是可选手段，不承诺严格朝代考据。
- 用户已明确希望较大农场的全景浏览，田块在全景中相对较小；点击某块田后相机平滑移动聚焦，再进行操作。允许围绕关注区域微调角度、平移和缩放；默认镜头应体现立面与空间层次，不能继续固定为上一轮近距离田格俯视。当前六田按权威状态显示正式三阶段作物，已实现全景 / 点击聚焦 / 微调 / 返回与复位以及整田农事工具；模型显示不承担田块点选身份。首版六田数量由 1.1 开发侧定稿，最终发行候选仍待后续验收。
- Windows 以外平台、账号与联网服务、云存档、复杂经济、任务惩罚、正式桌面宿主均未纳入当前建设范围。
