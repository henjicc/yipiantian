- 用户于 2026-09-17 确认直接切换 Godot，不再做引擎对比实验。仍先制作 Windows 普通窗口版三维农场小游戏，正式桌面壁纸宿主后置。实现默认采用带类型标注的 GDScript，当前为 Forward+ / Vulkan；精确版本以 [.godot-version](../.godot-version) 为准，首个可发布版本计划已获用户授权自主实施；用户最新明确禁止后续使用子代理，改由主代理独立执行；进度与定稿边界见 [任务总览](../docs/task/首个可发布版本/00-任务总览.md)，尚未实现部分以各任务状态为准。
- 创意目标：与现实时间同步、可以照料和布置、会持续生长的微缩农场，强调轻松、低打扰的观察和操作体验。规则以此指导后续取舍，不把创意清单全部作为已批准功能。
- 最新视觉方向为架空中国古代田园：宋明江南民居与生活气质。用户已选定第二轮 01 图的观察距离、整体构图与感觉，主图保存在 [制作基准包](../docs/design-baseline/README.md)。随后明确要求更圆润简洁的卡通形体，反对摄影级蔬菜细节，现已确认 A 工笔淡彩全景与 A 淡彩青菜的风格和质感；固定参考、原始提示词与复用模板见 [风格基准 v1](../docs/design-baseline/style-guide.md)。B / C 等保留为历史探索，不再待选。主图负责构图和空间氛围，不再用其微小写实纹理否定后续风格修正。低多边形只是可选手段，不承诺严格朝代考据。
