## 已确认基线与创意方向

- 用户于 2026-09-17 确认直接切换 Godot，不再做引擎对比实验。仍先制作 Windows 普通窗口版三维农场小游戏，正式桌面壁纸宿主后置。实现默认采用带类型标注的 GDScript，当前为 Forward+ / Vulkan；精确版本以 [.godot-version](../.godot-version) 为准，首版玩法仍待确定。
- 创意目标：与现实时间同步、可以照料和布置、会持续生长的微缩农场，强调轻松、低打扰的观察和操作体验。规则以此指导后续取舍，不把创意清单全部作为已批准功能。
- 最新视觉参考为架空中国古代田园：宋明江南民居与生活气质，吸收青绿山水配色，强调手作微缩模型和适度移轴感，优先从轴测或弱透视观察方式验证。低多边形作为可选实现手段，不要求画面呈明显块面或牺牲温润材质；不承诺严格朝代考据。
- 用户已明确希望较大农场的全景浏览，田块在全景中相对较小；点击某块田后相机平滑移动聚焦，再进行操作。允许围绕关注区域微调角度、平移和缩放；默认镜头应体现立面与空间层次，不能继续固定为上一轮近距离田格俯视。具体镜头参数、田块数量和内部种植位规模尚未锁定，当前仅有设计图，未实现相机功能。
- Windows 以外平台、账号与联网服务、云存档、复杂经济、任务惩罚、正式桌面宿主均未纳入当前建设范围。
