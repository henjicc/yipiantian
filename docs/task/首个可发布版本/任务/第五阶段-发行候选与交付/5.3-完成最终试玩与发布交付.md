1. 提供 5.2 的确切候选包与简短试玩路径：首次收获播种、照料、返回观赏、退出回访、解锁与布置；写清版本与存档边界。

3. 修复阻断与约定必须处理的问题，回到所属模块补验证；包或核心内容改变后更新候选、校验值及受影响的截图／录屏，不让宣传素材冒用旧版本。
4. 核对最终包、中文说明、已有来源／许可（商业核验按用户要求暂缓）、支持配置、已知问题、版本信息、截图和介绍满足 5.1 的实际渠道清单；素材中的 Tripo 名称及具体资产贡献真实可对应。
5. 检查首次使用、继续游戏、保存恢复和最关键性能证据仍适用于该包；把未验证设备或限制写入交付说明，不能在最后悄悄扩大兼容承诺。
6. 将交付路径、包校验值、用户验收意见、已关闭／明确接受的问题、待提交事项写入本任务和总览；保留制作过程资料的本地备份边界。
7. 当前计划以“已验收且可提交的发行交付”结束。若用户进一步要求实际上传／上架，追加明确目标的后续任务并按既有授权执行，不冒称本任务已经发布。
