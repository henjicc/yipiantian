# 2.2 接通播种浇水收获与镜头交互

## 任务状态

- 状态：实现与验证完成；共享入口／总览由主代理收口后提交。
- 所属阶段：第二阶段——可保存的种植闭环。
- 前置任务：2.1。
- 关联任务：2.3、3.1、3.3、4.1。
- 是否可以并行：可与独立资产制作并行；主控制、相机与场地文件由本任务单独修改。

## 任务目标

在现有六田场景中接通一种作物的整田播种、浇水和收获，保持全景浏览／聚焦／微调，确保界面、拖动、镜头过渡和农事动作不互相误触。

## 当前情况

- `main.gd` 只有点选、两个镜头按钮和状态文字；物理帧拾取队列与界面拦截可复用。
- `farm_camera.gd` 有过渡和返回，但尚无农事动作锁定或工具取消语义。
- `farm_layout.gd` 的 36 株青菜不随数据变化；已有 `tests/prototype_smoke.gd` 覆盖镜头和点选。

## 实施方案

场地仅展示 2.1 的权威状态，农事界面发出动作意图。新增一个当前工具选择与明确的取消路径，必要时将界面从主控制提取为独立场景。保留六田布局，先用青菜完成闭环，不倒回重做两田原型；未制作阶段可用清楚标记的开发占位，正式阶段由 3.1 接替。

## 执行步骤

1. 将田块绑定稳定标识，移除硬编码成熟株填充的状态来源，按空地／生长／成熟重建显示。
2. 加入播种、作物选择、浇水、收获入口和必要状态／失败反馈；动作只调用 2.1，动画不再写数据。
3. 明确全景点击只聚焦；切换别田清除或安全取消遗留工具，过渡中不执行农事、不把输入排队到落定后补做。
4. 实现同目标按下释放判定、拖动／失焦取消、界面遮挡拦截、右键取消与 Esc 优先取消再返回；保留中键转动、平移和全景恢复。
5. 为可重复验证使用隔离测试场景／可控时钟，走一次播种→浇水→成熟→收获；正式入口不加入默认加速或自动发奖。
6. 扩展现有真实输入测试，覆盖双击、快速换田、镜头过渡点击、界面按钮上释放、无效浇水、重复收获和小窗口布局。
