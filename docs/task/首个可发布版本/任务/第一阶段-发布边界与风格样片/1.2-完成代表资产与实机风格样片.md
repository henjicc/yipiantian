# 1.2 完成代表资产与实机风格样片

## 任务状态

- 状态：待开始。
- 所属阶段：第一阶段——发布边界与风格样片。
- 前置任务：1.1。

## 任务目标

用一块田、现有成熟青菜和一个民居代表部件验证工笔淡彩质感，并用低成本体块校准指定主界面的全景构图，确定批量资产的尺寸、材质与处理方法。

## 当前情况

- 快速校对用 [主界面参考](../../参考_主界面.jpg) 与 [蔬菜参考](../../参考_蔬菜.jpg)；原高清固定图在 `docs/design-baseline/images/approved/`，提示词与实际输入记录在同包 `style-guide.md`、`generation-record.json`。
- 现有 `ArtSource/Crops/Greens/greens_mature.blend` 与 `Game/art/crops/greens/greens_mature.glb` 可复用；三角形 2988、宽约 0.48 米，不代表最终笔触通过。
- 房屋、田块和树为 `farm_layout.gd` 内的简单几何体；当前画面与目标参考仍有差距。旧结构图不能直接当作最终风格输入。

## 实施方案

使用 [实施方案的资产流程](../../01-实施方案.md#五资产生产流程与分工)。先改善现有候选，再用一个民居外观部件验证图片工具→Tripo→Blender→Godot 的链路；不同时铺开所有作物和装饰。资金已授权，质量迭代围绕具体问题，不按固定次数机械停止或盲目重抽。

## 执行步骤

1. 打开两张快速参考、原高清图、成熟青菜源文件和现有全景；按实施方案校对表记录镜头、房屋与田园比例、水岸远景和笔触差异，不能仅凭面数换模型。
2. 选择一处后续一定采用的民居代表部件或简化整栋外观，定义可见面、尺寸、屋顶连接、接地原点与同屏数量。
3. 用图片生成工具以固定参考＋物件段生成单体图；检查干净背景、完整轮廓与正确结构。只对合格图进行 Tripo 生成，按 [参数起点](../../01-实施方案.md#tripo-生成方式与参数起点) 选择当前对象配置，保存真实参数、任务编号、原始输出和费用。
4. Blender 检查正背底面、实际三角形、UV、贴图与材质；调整尺度、根部／接地点和必要减面，另存可编辑源并导出 GLB。修改现有青菜前保留其整理成果，不直接重跑覆盖脚本。
5. 在独立 Godot 样片中用真实相机距离摆放代表田、青菜与建筑部件，其余院落、水岸、桥船和远山先用体块建立比例。按 16:9 校准默认全景，对照近景、转动和亮暗光照，记录材质、纹理与细节预算，不在本任务提前精做整套环境。
6. 向用户展示同一真实场景的少量代表画面，确认是否达到已定方向；只确认实机实现，不重开整体风格海选。确定后在采用资产记录中固定模型版本、实际参数、网格／纹理预算和适用对象，交给 3.1／3.2；一份青菜参数不直接当全部资产配置。
7. 按中文制作单元留存提示词、参考图、Tripo 原件、处理后文件、检查证据与最终采用位置，满足具体贡献归因。
8. 用同源青菜与民居代表部件比较高／低细节，验证自动 LOD 或必要减面的轮廓与笔触；在样片相机试温和景深，记录整田清晰范围和前后景观感。把可用方法与待定阈值交给 3.1／3.2／3.5，不在此实现完整焦点控制。

## 验收标准

- [ ] 用户对真实引擎样片的画风反馈明确；未确认时留“待验证”，不宣称批量风格已通过。
- [ ] 有主界面参考与实际全景的并排对照，镜头和主要景物比例已校准，剩余环境缺口明确交给 3.2／3.3。
- [ ] 全景与近景可辨，微调不露明显缺面／笔触破洞；形体圆润、保留淡彩层次且无摄影微纹理或塑料高光。
- [ ] 尺度、枢轴、材质、实际三角形与贴图有记录；GLB 独立重导入正常。
- [ ] 代表资产可在后续正式场景复用；没有产生第二套玩法或破坏现有相机。
- [ ] 提示词、原始模型、处理及真实费用齐全；来源初核交接给 5.1，总览同步。
- [ ] 代表资产高低细节及轻微景深有真实对照，薄叶、屋顶等易失真部位可辨；后续制作有可复用约定。
