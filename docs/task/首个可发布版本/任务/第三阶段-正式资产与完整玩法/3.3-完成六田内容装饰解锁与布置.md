# 3.3 完成六田内容装饰解锁与布置

## 任务状态

- 状态：待开始。
- 所属阶段：第三阶段——正式资产与完整玩法。
- 前置任务：2.3、3.1、3.2。
- 关联任务：3.4、4.1、4.2。
- 是否可以并行：可与 3.4 的独立氛围／音频资源工作并行；主场景和存档字段修改由本任务负责整合。

## 任务目标

把已可保存的一种作物切片扩为定稿的完整首版内容，形成首次可操作、长期可回访、有少量布置目标的真实农场。

## 当前情况

- 当前原型已有六田空间，但没有两作物和装饰逻辑；前置任务将提供状态、可靠保存与正式资源。
- 草案为累计收获解锁三件装饰、固定位置摆放，不消耗货币；实际门槛以 1.1 为准。
- 2.3 之后已经存在正式格式与玩家数据，不能通过重置农场接入新内容。

## 实施方案

新增萝卜静态定义并复用同一结算逻辑；阶段资源按状态映射，田块稳定标识不变。装饰使用小型解锁／占位状态与固定位置，不预建自由建造系统。首次初始田况只在无存档时生成；对已有档补字段时保留种植和收获。

## 执行步骤

1. 核对三方交接文件、作物标识与阶段映射，将两种作物全部阶段和正式环境接入六田主场景，移除被替代的占位分支。按 [主界面参考](../../参考_主界面.jpg) 调整默认全景的距离与构图，保留已验证的聚焦／返回／微调能力。
2. 配置首次农场的成熟田、空田与不同进度田；确认再次进入、相机复位和升级读档不重新发放初始收获。
3. 实现按作物累计收获与一次性装饰解锁；达到门槛解锁但不扣收获，重复结算不重复创建物件。
4. 加入布置入口、合法位置预览、确认、移动与取消；占用冲突拒绝，挂件与地面物件的位置类型匹配。进入布置回全景并清除农事工具。
5. 将装饰解锁与位置存档；明确旧版本缺字段的补全或迁移方法，保留原档与测试样例，取消预览不得落盘改变原位置。
6. 用可控时间验证多个循环与全部门槛；另做真实等待／回访体验，记录首次是否能看懂操作、长等待是否有目标，必要调数值但不增加经济系统。
7. 增加双作物、解锁幂等、占用、取消、退出重开和旧档兼容回归，更新玩法与内容清单。

## 数据变化

新字段和静态定义变化必须说明格式版本与旧档处理。累计数量不因配置门槛调整而丢失，已合法解锁的装饰不随调参回收；如需不同规则，先更新方案并确认玩家数据影响。

## 验收标准

- [ ] 六田、两作物及全部阶段可种可收，首次初始化与回访路径正确。
- [ ] 默认全景的民居、田园、桥船、水岸及远景关系接近指定参考；真实聚焦和微调不露底、不遮住必要操作。
- [ ] 三项定稿装饰可解锁、摆放、移动、取消并在重开后保持；不能叠放或重复发奖。
- [ ] 农事与布置互斥，退出／取消／换田无遗留误操作。
- [ ] 新老格式测试和实际重开通过，初始成熟奖励不重复。
- [ ] 有完整循环与节奏试玩记录，玩法文档、资产清单和总览同步。
