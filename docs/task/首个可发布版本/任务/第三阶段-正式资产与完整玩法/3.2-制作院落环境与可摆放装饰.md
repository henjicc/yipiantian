# 3.2 制作院落环境与可摆放装饰

## 任务状态

- 状态：待开始。
- 所属阶段：第三阶段——正式资产与完整玩法。
- 前置任务：1.2。
- 关联任务：3.1、3.3、3.4、5.1。
- 是否可以并行：可与 3.1、独立玩法模块并行；环境源文件与作物源文件分开，主场景整合留给 3.3。

## 任务目标

交付符合指定主界面参考的民居、田园、水岸桥船、入口植被与远景，以及可解锁摆放的陶罐、花盆、灯笼；替代明显占位体块，并保留全景留白和操作可见性。

## 当前情况

- `farm_layout.gd` 程序化生成房屋、围栏、道路、树和水岸，无对应正式可编辑模型。
- 用户已明确本计划主界面图为最终实机的主要还原依据；桥船、水岸与远景已纳入视觉范围，村落可表现为远岸轮廓，不增加对应玩法。对象和数量起点见 [首批资产清单](../../01-实施方案.md#首批资产清单与制作方式)。
- 1.2 将提供民居代表资产与实机风格参数；不能重新支付生成同一已合格部件。

## 实施方案

按 [主界面参考](../../参考_主界面.jpg) 的实际景物层次及 [统一资产流程](../../01-实施方案.md#五资产生产流程与分工) 制作。民居外观、木船、代表树形、景观植被和三件装饰优先 Tripo 整件或部件；接缝严格的田块、石路、石桥结构、篱笆及碰撞用 Blender／Godot。水面效果在 3.4 实现，本任务交付几何与摆放条件；桥船作为景物，不做室内、开门、物理建造或航行玩法。

## 执行步骤

1. 以 1.2 构图结果和主界面参考列出景物清单：民居与屋顶、入口棚架、田块石路、围栏水岸、石桥木船、树木花草、远山远岸和三种可摆装饰；区分已有复用、需生成、精确建模与背景对象，固定位置／体量和摆放规则。
2. 复用合格部件；对其余对象生成单体参考图，检查门窗、屋顶、开口、把手、底面与树形连接，避免整座农场一次生成成不可编辑网格。
3. 对明确候选按 [参数起点](../../01-实施方案.md#tripo-生成方式与参数起点) 调用 Tripo，按对象记录实际配置、原始输出、模型版本、费用和采用判断；Blender 按需修比例、厚度、接地与贴图，必要时组合建筑部件。
4. 制作可复用田块／道路／桥岸／围栏模块，校验尺寸与接缝；每个装饰定义根部或挂点，不把灯光烘焙进不可变高光贴图。为远山远岸验证简化三维或分层背景，在允许的镜头范围内不露边、不穿插，不能把整张参考当可交互场景。
5. 输出环境与装饰独立组合场景，登记占地、可旋转范围、碰撞及预设位置标识；交给 3.3 负责主场景整合。
6. 将环境样片与参考按相同比例并排，核对房屋／菜田／桥船位置、院落丰富度、水岸和远景层次；再检查镜头极限的背面、边缘和前景遮挡，对照近景笔触，不能只还原配色。
7. 更新实际资产清单与中文留档，明确哪些网格／部件由 Tripo 生成，哪些由 Blender／Godot 制作。
8. 为民居、树、桥船和重复植被按镜头占比验证高低细节，优先自动 LOD，必要时 Blender 从同源整理低细节；保住屋檐、桥拱和树冠轮廓。记录可共用单档的简单模块，向 3.5 交付资源映射和导入配置，不重新生成每一档外形。

## 涉及内容

### 新增文件

- `ArtSource/`：民居、环境与三件装饰的源资产、采用参考及来源记录，具体分目录实施时登记。
- `Game/art/`、`Game/scenes/`：正式导出物与环境／装饰组合资源，包含必要的摆放标识约定。
- `制作留档/`：图、模型、处理与贡献副本。

### 修改文件

- `docs/design-baseline/asset-list.md`：实际数量、采用状态和资源位置。

### 可能废弃

- 原程序化占位房屋／树等分支：由 3.3 完成替换并验证后再移除，本任务不提前删掉可运行场景。

## 验收标准

- [ ] 民居、田园、水岸、石桥木船、入口与植被、远景和定稿装饰构成接近参考的整体环境；桥船保持景物职责，没有新增航行、室内或角色系统。
- [ ] 全景构图、田块间通路与可点选性保留；聚焦和极限微调不露明显破面或无出口遮挡。
- [ ] 模块接缝、尺寸、枢轴、贴图、实际预算与重导入检查通过。
- [ ] 三种装饰有清楚的摆放／挂点要求，可供 3.3 做占用与保存。
- [ ] 来源、实际成本、贡献与交接文件完整，资产表及总览同步。
- [ ] 参考与环境样片有并排校对记录，省略或简化项写明视觉影响，不把低细节占位体块当成最终还原完成。
- [ ] 需要降级的复杂／重复环境有可用低细节，轮廓和色层连续；资源可被独立控制，不因整场合成一个网格而丢失焦点分级能力。
