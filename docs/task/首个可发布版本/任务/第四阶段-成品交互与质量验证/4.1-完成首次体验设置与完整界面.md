# 4.1 完成首次体验设置与完整界面

## 任务状态

- 状态：已完成；正式界面、独立设置持久化、键鼠边界、普通发行程序与尺寸 / DPI 验证已通过，交接见 `handoffs/4.1-handoff.md`。
- 所属阶段：第四阶段——成品交互与质量验证。
- 前置任务：3.5（已包含 3.3、3.4 的整合）。
- 关联任务：4.2、4.3、5.1、5.2。
- 是否可以并行：素材来源整理可并行；本任务统一界面及启动／退出路径，不与其他任务同时修改。

## 任务目标

让首次玩家和回访玩家无需开发者讲解即可进入、操作、调节声音／显示并安全退出；保留田园画面主体，形成可发行的完整使用流程。

## 当前情况

- 原型 `main.gd` 动态创建标题、状态和两个按钮，使用系统微软雅黑字体；没有设置、继续游戏、恢复入口或来源页面。
- 前置任务提供农事、布置、保存反馈和声音，但需要统一成品入口与状态层级。
- `rules/frontend-ui.md` 禁止未获要求的冗长帮助文案；用户本次成品目标不应被解释为网页式面板或强制教学。

## 实施方案

按 1.1 的最小成品界面定稿实施，不强制新增独立标题页。首次进入和正常继续明确，成熟田和空田让首次操作自然发生；必要的设置、操作查看、恢复和退出有可靠入口。字体采用已核验可随包分发的方案，不能直接复制系统字体当游戏资源。

## 执行步骤

1. 走查首次缺档、正常回访、保存失败、恢复、全景、聚焦、布置与退出路径，整理界面状态及取消优先级。
2. 按 [主界面参考](../../参考_主界面.jpg) 整合界面：左上收获信息、右上真实时间／日夜信息、下方播种／浇水／收获按钮，采用浅色圆角底与克制描边；额外返回／设置入口避免抢占主体画面。图标清楚，状态不只靠颜色，所有文字和控件由运行界面真实绘制。
3. 接入定稿的声音、窗口／全屏和必要画质设置；设置保存失败与玩法存档失败区分。画质设置复用 3.5 的细节与景深入口，允许减弱／关闭景深而不关闭 LOD；只调实际有收益的项，不预建大量选项。
4. 处理首次／继续进入和退出流程：设置开关或返回不重新初始化农场，未保存状态不被假报成功；不默认加入删档／重置按钮。
5. 确定可分发中文字体、游戏图标与必要操作图，核对来源后接入；不要将概念图中的文字或博物馆图直接放进界面。
6. 在目标窗口与 4K／高 DPI 下检查布局、键鼠焦点、标签可读性与设置恢复；新增入口不穿透到田块，Escape 和右键行为一致。用默认全景真实截图与参考并排检查界面位置、比例和整体效果；实际数值随存档和时间变化，不为贴图一致而固定假数据。
7. 进行一次未看开发说明的首次体验走查，记录误解与阻断；补必要提示而非不断加说明段落。
