# 3.4 水面与远景视觉修正交接

## 状态与触发

水面／远景修正已完成定向实景验证，根代理独立复看第四版日间图后接受方向；等待院落密度所有者最后点击回归和统一视觉冻结。5.3 固定参考对照暴露大片近纯色水、村落／柳岸消失等明显差距，根代理暂停旧 4.2 长测并安排有界修复；这不是新增玩法或降低原视觉目标。

## 已查根因与范围

- 现有 `Game/art/environment/backdrop/river-distance.png` 本身含村落、柳岸、远山和淡彩水纹，无需重生成。环几何高 `20..-50m`，图中水岸约 `v=.72` 原映射至 `y≈-30m`，正常镜头被近水遮住／裁切；原下缘还直接混成纯色。
- `quiet_water.gdshader` 原 ALBEDO 常量，只有很小法线波，无法在全景形成参考中的水色明暗。
- 本修正只拥有 `Game/atmosphere/quiet_water.gdshader`、必要 `day_night.gd`、`Game/scenes/environment/backdrop.gdshader`。院落植被／岸石密度由另一代理改 `courtyard.gd`；相机、UI、玩法、存档不动。

## 最终采用方法

- 保留半径 65m、上下沿 `20..-50m`、192 三角的环形承载几何，横向仍随世界方位镜像采样。纵向改为每个观察方位的远竖平面投影：由片元世界射线、相机水平朝向和至原点后方 65m 平面的距离求绘画高度，再映射 `v=(20-height)/70*2-.42`。这避免直接圆柱映射造成弯碗形水岸；没有改相机控制或近景真实 3D 几何。
- 图像水部下裙 `v=.80..1.05` 渐混为远水色，避免把竖倒影无限拉伸为反射墙。近水径向 `13..23m` 淡出，使画中村柳岸能显露；原 `22..35m` 淡出会遮住这些中景。
- 水面仅取同张图底部 `v=.90.. .98`、权重 `.07` 作为静止世界坐标淡彩底；弱横向微光幅度 `.018`、低频色层 `.012`，远处渐淡，不滚动画笔纹理。没有新增纹理、生成调用、SSR、反射探针或每帧 CPU 工作。
- 岸边接触读取实际不透明深度，经逆投影／逆视图矩阵还原世界位置，用水面与下方表面高度差染色；不以椭圆／环形函数假造岸线。公式按 [Godot 官方深度重建说明](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html) 核对 Forward+ Vulkan reversed-Z 的 `[0,1]` NDC；透明材质限制依 [Spatial shader 说明](https://docs.godotengine.org/en/stable/tutorials/shaders/shader_reference/spatial_shader.html)。

## 实际验证与边界

- 真实 Godot `4.7.2.stable.official.ed1daf0bf` / Forward+ / RTX 4090，`tests/complete_scene_test.gd` 第四版 **34 checks / 0 failures**、退出 0、无 shader／引擎错误。该测试使用独立 FarmStore／SettingsStore，不操作玩家档。
- 已逐张实看第四版 `01-initial-day.png`、`06-night.png`、`05-overview-limit.png`、`04-focus-limit.png`：山→村柳岸→远水层次可见，强放射拉伸消除，夜间衔接自然、田况可读，转动极限显示不同方位的远景而非锁死整图，近景俯视只有局部水；未见环边、硬接缝或露底。HUD 仍显示真实本地时间，夜图是测试视觉预览；不会冒称系统时刻已经变成夜晚。
- 第一版将水岸抬得过高、出现夸大的水纹，第二版仍被近水遮住，第三版出现弯碗形岸线；均是被否决的中间图，不作最终展示。第四版通过根代理日间独立复看，不据此声称全部最终验收已完成。

- 新材质增加一份已有纹理采样与一份深度采样；无新进程／定时器。性能需重跑 4.2，不沿用中断旧样本或拿截图帧率冒充最终性能。
