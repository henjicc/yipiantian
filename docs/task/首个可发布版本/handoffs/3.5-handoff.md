状态：**实现、正式场景图像和必要回归完成，交主代理提交**。2026-09-17；本代理未提交。GPU、main与HUD已释放给4.1，无遗留运行窗口，不额外录制阶段视频。

## 最终显示策略

`Game/presentation/focus_detail.gd` 只持有派生显示目标，不读取FarmState或Store。主场景既有选择在镜头移动前调用 `set_focus(field)`；返回／布置调用 `set_focus()`。当前田作物bias=128，其他作物、复杂环境与装饰bias=0，使用实际自动LOD索引。不切换GLB、不重建Mesh／材质／碰撞，无旧目标异步回调。播种／成长阶段、装饰预览／恢复通过已有子节点入树事件继承偏置，不每帧扫描资源树。

真实反证：所有环境最低自动LOD会让低面石路、桥扶手、栏杆消失。因此初始化按稳定源路径 `res://art/environment/modules/` 分类，保留其bias=128；复杂资源才用最低自动层。无景深近景对照已确认修复，环境原有高低节点与布置BVH不变，无新网格冷建。

景深使用CameraAttributesPractical：整田含植物的2.8×0.75×2.3m包围盒（原点-1.4,-0.1,-1.15）八角投影深度，两侧留0.6m；相机更新后计算，向外立即扩张，向内按 `1-exp(-8*delta)` 收缩。最高量0.045，近远过渡2／5m，距离18→12m渐入，强度变化速度0.12/s；换田先清旧焦点。全景／布置关闭，代表聚焦最终清晰带7.334..11.754m。旁田虚化取决于深度，同深度邻田可能同样清晰，其细节区别由LOD完成；UI不经过3D景深。

## 冻结接口与4.1接入

公开 `scene.focus_detail` 在ready已configure，4.1调用并由统一设置owner保存：

```gdscript
configure(camera: Camera3D, fields: Array, environment: Node3D, decorations: Node3D) -> void
set_focus(field: Node3D = null) -> void
set_quality(value: String) -> bool # standard / low，非法值false
set_depth_of_field(enabled: bool, strength: float = 1.0) -> bool
get_settings() -> Dictionary # {quality, dof_enabled, dof_strength}
refresh_field(field: Node3D) -> void
refresh_decorations() -> void
refresh_details() -> void
```

标准=4×MSAA+用户景深偏好；低档=2×MSAA+暂时关闭实际DOF，保留enabled/strength，切回标准恢复。关闭DOF不影响LOD。强度夹0..1，非有限数拒绝，get_settings返回独立字典。MSAA采用已有Viewport属性，不增额外设置，不变阴影或当前田高档。4.1接入后为测试注入隔离settings_store，避免读玩家偏好。

## 实际资源与官方依据

本地Godot4.7.2官方版Forward+，审计RenderingServer surface真实LOD索引：63个surface中49个带LOD，不由import开关推断。六作物高档自动层：青菜700→388、2006→1106、2988→1494；萝卜700→366、1998→1118、3200→1916。民居主网格20961→14303另24面补孔，树24718→12280，竹13649→7809，船17561→8779，藤架21232→10384。已交付手工低档保留，本实现无需额外资源切换。

官方依据：[实例偏置](https://docs.godotengine.org/en/4.7/classes/class_geometryinstance3d.html#class-geometryinstance3d-property-lod-bias)、[视口LOD阈值](https://docs.godotengine.org/en/4.7/classes/class_viewport.html#class-viewport-property-mesh-lod-threshold)、[渲染统计](https://docs.godotengine.org/en/4.7/classes/class_renderingserver.html)、[景深](https://docs.godotengine.org/en/4.7/classes/class_cameraattributespractical.html)、[VSync](https://docs.godotengine.org/en/4.7/classes/class_displayserver.html)。bias0强制最低层，viewport阈值0仅测试全高；CPU为视口渲染加frame_setup，不含全部脚本物理，GPU需先启用测量。

可见图元下降44.0%／37.6%。全景实际DOF为0，聚焦0.045。短测可分辨景深开销，不宣称持续性能通过或低档必然固定比例提速；先前60fps受限样本时间非单调，功耗／频率影响比较，4.2用≥60s每状态及30分钟收敛。实际分辨率用 `get_texture().get_image().get_size()`；本机缩放窗口Texture声明曾误报7680×4320，不据此声称8K。
