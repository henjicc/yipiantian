## 已交接口

`res://audio/farm_audio.gd` 为 Node，每个 SceneTree 只允许一份，创建四个游戏总线并复用已有同名总线，不改默认总线资源：FarmMusic→FarmMaster→Master；FarmAmbient→FarmEffects→FarmMaster。

```gdscript
func set_volumes(master: float, music: float, effects: float) -> bool
func get_volumes() -> Dictionary
func set_foreground(active: bool) -> void
func is_foreground() -> bool
func set_night_weight(weight: float) -> void
func play_action(tool: String, result: Dictionary) -> bool
func play_ui() -> bool
```

音量为 0..1，有限值夹紧、NaN/Inf 拒绝；getter 返回副本，默认 .8/.7/.8。4.1 用自己的已验证持久化设置调用 setter，不从实际总线 mute 反推用户设置。音乐与环境循环失焦后暂停当前位置，恢复继续；操作／界面声失焦时停止，后台动作不排队。最终静音是“用户为零或不在前台”，不会改写用户音量。Music 单独控制背景曲，Effects 同时控制环境与操作／界面；内部 Ambient 仍独立，以便混音。

`play_action` 仅接受 tool=sow/water/harvest 且 result.ok=true；未知／失败动作无声。全局 160ms 动作限频，两个固定声部，满时丢弃额外声音而不中途截断；界面单声部至少 100ms。返回值表示本次声音是否实际开始，不改变农场 result、收益或存档。3.3 从 `_apply_tool` 拿 tool 与成功 result 调用，不对每株重复触发。

`res://atmosphere/window_activity.gd` 为独立 Node，观察真实 Window 焦点和最小化，发 `foreground_changed(active)`；正常 `.25s` 补查防漏通知。后台 Engine.max_fps 最大 15，前台恢复进入时捕获的帧率；`set_foreground_frame_limit(limit)` 可更新该前台值，退出恢复。**不设置 SceneTree.paused、Engine.time_scale，不调用 farm 或修改 UTC。**

```gdscript
activity.foreground_changed.connect(audio.set_foreground)
add_child(activity)
audio.set_foreground(activity.is_foreground())
```

`res://atmosphere/day_night.gd` 为纯显示 Node：

```gdscript
func configure(sun: DirectionalLight3D, world: WorldEnvironment, water: MeshInstance3D = null) -> void
func set_lantern_anchors(anchors: Array[Node3D]) -> void
func set_backdrop_material(material: ShaderMaterial) -> void
func set_preview_hour(hour: float = -1.0) -> bool
func get_night_weight() -> float
func ripple_at(world_position: Vector3) -> void
signal night_weight_changed(weight: float)
```

先 add_child 再 configure。昼夜读取 `Time.get_datetime_dict_from_system(false)` 的本地时分秒，测试以 `set_preview_hour` 注入，-1 返回真实本地时间；不改系统时钟。固定时间锚点 0/5/6.5/9/16/18/20/24，以 smoothstep 连续插值。正午沿 1.2 线性色调、sun .80/fff8ea、ambient .40/e6e9dd；夜间 sun .15/a9c3dd、ambient .45/a5b8d5，雾 .0012。保持方向光原旋转，不引入天文或日照产量。

绑定正式 `courtyard.get_water_surface()` 后直接接管 `material_override`，不能只设 surface_override：院落初始整材质会优先生效。水色沿正式 b3c9bf，仅极小法线微动与一次有限衰减涟漪，不平移静态画笔纹理；按 3.2 实景接缝要求，在世界 XZ 半径 22..35m 淡出至全环远水，blend_mix、不用 depth_prepass_alpha，近水仍不透明。全环背景 unshaded，需要 `set_backdrop_material(courtyard.get_backdrop_material())`；3.2 已补 atmosphere_tint uniform，夜权重从白色渐变到 7086a0，正式昼夜全景已确认远景随夜色变暗、没有亮白天空或远水硬边。

只传**当前真正放了灯笼**的顶环挂点；重新布置后重新 set_lantern_anchors，旧灯安全移除。每灯向下 .22m，范围 2.8m、无阴影、暖色 ffd296，夜权重×.70 能量；未解锁／未放置挂点不发光。

```gdscript
atmosphere.night_weight_changed.connect(audio.set_night_weight)
audio.set_night_weight(atmosphere.get_night_weight())
```

## 音频来源与检测

`ArtSource/Audio/compose_farm_audio.py` 为原创程序作曲／合成源，`score.json` 为 128 秒 / 60 BPM / 八个四小节乐句，筝类拨弦与笛类气息合成音色，**不冒称真实乐器或田野录音**。日夜环境床各 64 秒，四操作声分别 .48 / 1.15 / .65 / .13 秒。media-use 目录调用因本机没有 HeyGen CLI 返回失败，未采用外部音源，也未继续账户、付款或商务核验。

母带 `ArtSource/Audio/masters/*.wav` 为 48kHz 双声道 PCM24；正式 `Game/art/audio/` 三个 OGG 循环、四个 PCM16 WAV。3 个 `.ogg.import` 的 loop=true 已真实跨末尾验证。来源／处理／指标见 [音频说明](../../../../ArtSource/Audio/README.md)、`audio-report.json` 和 `validation-report.json`。全部零削波，4× 真峰值最高 -13.07dBFS，曲 -26.95 LUFS，环境约 -35 LUFS；.13 秒 UI 音不足响度门限，不把 -inf 误报为没有声音。循环首尾采样差低于片内正常采样差，另保存尾8秒＋首8秒的拼接检查文件。

**听感限制**：原生 audio 输出实测返回“audio content omitted because you do not support audio input”。当前模型无法直接听音，尚未完成主观音色／节奏／循环听感复核。不能把技术测量、非零输出或播放成功称作已经听过。主代理已确认不安装新服务、不等待用户，继续可完成工作并在最终展示提供可播放素材。

中文留档：`制作留档/06_声音制作/01_原创声音源/` 为完整源与母带副本，`制作留档/06_声音制作/田间慢声_完整配乐.mp3` 为供用户直接播放的 192kbps 完整曲；`制作留档/03_处理与验证/05_昼夜与声音/` 保留初始截图、短有声输出、提取混音、检测报告和循环拼接预览。

## 4.3 音轨边界

已用本地 Godot MovieMaker 实际输出 `.local/atmosphere-validation/audio-proof-clean.avi`：125 帧 / 30fps / 4.166667 秒，3840×2160，MJPEG + **48kHz 双声道 PCM16**。提取混音 200000 帧，峰值 .17160、RMS .02571、零削波，确有声音，不只空音轨。首轮因播放节点尚未释放退出有清理警告，测试显式 free 样片并等待两帧后重录已无警告。

NVENC MP4 对照 `.local/atmosphere-validation/audio-proof.mp4` 有 H.264 4.166667 秒和 AAC48k 双声道 4.166 秒，时长差 <1ms。最初 `scripts/record.ps1` 明确 audio=none／`-an`，旧片确实无音；3.3 所有者现已获授权新增 `-WithAudio`（仅 MovieMaker 演示）、AAC192kbps／48k双声道分支和检查。正式40秒院落有声片由3.3继续验证，不能用本次4秒样片替代其成片证据。4.3继续要求 ffprobe 有音轨、非零解码及音画时长匹配；不能只删 -an 就声称通过。

本次短 AVI 是独立测试夹具，显式释放 WindowActivity 并设 audio 前台，以校验离线音轨，**没有改变真实游戏失焦静音策略**。3.3 的正式离线录制分支限制在既有开发 session、MovieMaker feature 与 capture_audio=true 同时成立；发行和普通后台必须继续静音。本次完整主场景最小化测试已再次验证该边界。旧开发录像仍无声，实时桌面捕获音轨尚未核验。本代理未修改共享录制脚本。

官方契约复核：[AudioServer](https://docs.godotengine.org/en/4.7/classes/class_audioserver.html)、[AudioEffectCapture](https://docs.godotengine.org/en/4.7/classes/class_audioeffectcapture.html)、[Window](https://docs.godotengine.org/en/4.7/classes/class_window.html)、[MovieMaker](https://docs.godotengine.org/en/4.7/tutorials/animation/creating_movies.html)。采用行为另有上述本地实测。
