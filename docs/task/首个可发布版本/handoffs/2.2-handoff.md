## 权威状态、时钟和 2.3 接入点

`main.gd` 持有 `farm_state: FarmState`，唯一 UTC 读取入口为 `clock: Callable = Time.get_unix_time_from_system`。测试在场景加入树之前注入返回固定 UTC 的 callable，不改系统时钟、不读写玩家存档、不加产品加速入口。

- `_ready()`：当 `farm_state == null` 时用当前 UTC 初始化初态。**2.3 必须在这里完成加载／恢复边界，不能坏档时沿用这个新建分支并覆盖玩家数据。** 可在入树前赋入已验证的 `farm_state`，或在此接独立存储组件；加载仅执行一次。
- `SettlementTimer`：每秒调用 `settle_farm()`，统一结算后调用 `refresh_farm()`；焦点恢复同样结算。周期结算目前不发 `farm_changed`，2.3 的定时保存应在明确的保存调度点获取最新 `snapshot()`。
- `_apply_tool()`：只调用 `FarmState.sow/water/harvest`。成功后清工具、刷新并发 `farm_changed(result: Dictionary)`。2.3 可在此监听成功动作请求保存当前快照；失败不发信号，不重放动作修复写入失败。
- `refresh_farm()`：从每个稳定 ID 的 `get_field()` 刷新场景，从 `snapshot().harvested` 刷新累计篮数；存档恢复后复用这一入口。
- 当前没有磁盘 I/O，也没有退出保存。HUD `HUD/Layout/SessionStatus` 明示“试玩中 · 进度尚未保存”；2.3 接好保存后应替换为真实保存／失败状态，不能保留过期限制。

不要从视觉节点、按钮文字或动画反推状态；不要另存一套收获计数。播种和浇水规则、时长、累计全在 2.1。

## UI 节点与意图

`HUD` 是 CanvasLayer，脚本运行时生成 `Layout`：

- `FieldStatus`：第几块田、作物、阶段、约剩余分钟与已浇水；空田显示空田。
- `Harvested`：青菜与白萝卜累计篮数。
- `Feedback`：动作结果／无效原因；不把失败播放成成功。
- `ToolStatus`：选中工具／镜头移动状态。
- `FarmControls/CropChoice`、`Sow`、`Water`、`Harvest`：仅聚焦田块时显示，镜头移动中禁用。
- `ViewControls` 的前两个按钮依旧为全景／视角复位，保留既有原型测试路径。

HUD 发 `tool_requested(tool)`、`crop_requested(crop_id)`、`overview_requested`、`reset_requested`；主场景调用 `show_state`、`show_result`、`clear_feedback`。工具 ID 为 `sow/water/harvest`，作物 ID 来自 `crop_catalog`。工具选中可再次点击取消，成功动作自动清除；失败保留工具并显示原因。

4.1 可统一最终样式与布局，但需保留意图／权威规则边界及这些实际可操作状态。当前原型环境与布局未被本任务当成最终视觉验收。

## 输入契约

- 全景点击只聚焦，不执行农事；聚焦后先选工具，再点当前田。
- 换田清工具，最新选田可替换未完成镜头目标。右键／Esc 优先取消工具，第二次返回全景；弹窗打开时 Esc 先关闭弹窗。
- 世界点击从 `_unhandled_input` 入队，物理帧射线拾取；UI 吞掉的事件不生成世界动作。
- 按下和释放必须命中同田、位移不超过 7 像素；双击第二击、取消事件、拖动、失焦、鼠标离开、在 UI 上释放均取消旧手势。
- 按下、释放时的镜头过渡状态与工具／选田上下文随手势保存，处理时再次检查。过渡内按下、落定后释放仍拒绝，不把旧输入延迟执行。
- 中键转动，Shift＋中键平移，滚轮缩放；镜头操作取消未完成的左键手势。聚焦返回仍恢复之前全景位置、角度和距离。

## 3.1／3.3 必须替换的临时视觉

全部在 `farm_layout.gd/show_field()`：

- 青菜幼芽／幼株临时缩放旧 `greens_mature.glb` 至 0.28／0.62，成熟 1.0；此举只验证可见阶段切换，**不是正式阶段美术**。
- 萝卜临时用缩放青菜叶加白色球体表示，`Label3D` 显示“白萝卜 · 阶段示意”；青菜非成熟显示“阶段示意”。3.1 接真实三阶段模型时删除这些示意标签和替身组合，3.3 不得把它们当已完成资产沿用。
- 每田 `StaticBody3D` 带 `field_index`（瞬时拾取）与 `field_id`（稳定身份）；`field_id(index)` 返回身份，节点显示名／模型重建不决定身份。
- `Crops` 容器只在作物／阶段／浇水可见 key 变化时重建，平常每秒更新时间不重建；湿土由 `watered` 派生。字段中时间基准变化不是模型替换理由。
- 当前成熟田另有“可收获”标记；未来换美术需继续保证成熟与选中可识别。

## 可复用经验与共享文档待主代理收口

- Godot 4.7.2 的 PopupMenu 使用窗口输入路径。普通场景输入回归用 `root.push_input(event)`；实际弹窗键盘回归用 `InputEventKey.window_id = popup.get_window_id()` 再 `Input.parse_input_event(event)`，不直接 emit 选择信号、不调业务私有方法替代 UI。
