## 3.3 / 3.5 直接接入契约

入口 `Game/art/crops/crop_visual_catalog.gd` 是纯视觉映射，无状态和 Autoload：

```gdscript
static func scene_path(crop_id: String, stage: String, low_detail: bool = false) -> String
static func instantiate(crop_id: String, stage: String, low_detail: bool = false) -> Node3D
static func planting_depth(crop_id: String, stage: String) -> float
```

非法作物／阶段的路径返回空串，实例化返回 null。默认高档；模型已经是米制，不要再按成长进度缩放。玩法阶段仍由 FarmState 返回，不能从模型尺寸／节点名反推存档状态。

```gdscript
const CropVisuals = preload("res://art/crops/crop_visual_catalog.gd")
var crop := CropVisuals.instantiate(crop_id, stage, low_detail)
if crop != null:
    # soil_anchor 是既有种植点，位置与随机朝向对所有阶段保持一致。
    soil_anchor.add_child(crop)
    crop.position.y = -CropVisuals.planting_depth(crop_id, stage)
```

源文件原点始终是根尖／根底，不能改源原点来埋土。视觉映射给出固定种植深度：青菜三阶段均 0；白萝卜幼芽 **.003m**、幼株 **.020m**、成熟 **.060m**。它们是土面到根尖的距离，高低档共享，不随镜头／时间变化；土面锚点的 X/Z 和朝向在阶段替换时保持。成熟白根肩保留地上识别，下方短钝尖埋入土面。补充实际种植特写见验收记录。
