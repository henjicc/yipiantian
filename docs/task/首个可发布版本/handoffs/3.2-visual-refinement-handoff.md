## 原因与本次修正

5.3独立复核发现岸边稀疏、石缘过于均匀、院落接地感不足；与固定参考比较后，暂停持续性能和候选打包，先修正已有场景。

- 复用五类岸石，调整高低、大小、断续与暖灰绿色差，增加七处双石浅滩及对岸七组石脚；维持桥落岸和船位置。
- 原有树／竹／花／荷叶资源扩为7棵树、19组竹（含缩小的岸草）、45组花、16组荷叶；树冠集中于后侧，低矮层留在田外与岸边。荷叶分为四个松散水湾，避免等距项链式排布。
- 前田外侧复用三段低竹篱。两条非交互小木凳为Godot代码生成，每条六个BoxMesh，共144三角形；不是Tripo或Blender新资产，也不复制三件解锁装饰。
- 花丛下15片静态不透明弯曲草叶，每片30叶、210三角形，总3150三角形；无透明卡片、逐帧动画或处理。几何源为 `courtyard.gd` 的 `_grass_patch`，木凳源为 `_build_porch_bench`。
- 本次没有新图像生成、Tripo调用或Blender加工，新增生成费用为0；原资源来源和成本继续沿用原交接。复杂资产共90对独立高／低实例，未合并整院落、未改既有LOD接口；这是实例数，不是实际绘制量。

六田ID、中心、土壤尺寸、初始存档、种植点、作物尺度和八个装饰Marker变换均未改。水／远景的独立修正见 [3.4视觉补修交接](3.4-visual-refinement-handoff.md)，由另一子代理负责。
