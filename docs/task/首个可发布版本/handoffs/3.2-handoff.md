## 3.3 / 3.5 稳定接口

`courtyard.tscn` 依赖纯定义 `res://farm/decoration_catalog.gd`（3.3代理拥有，主代理随3.2先行提交此文件及uid，避免基线缺依赖）。除此不依赖3.3状态、3.4水/音频文件。

- `get_decoration_scene(item_id,low_detail=false)->PackedScene`，玩法 `pot` 映射资源 `jar`，另有flowerpot/lantern。
- `get_decoration_slots()->Array[Dictionary]` 字段id/type/transform/allowed_turns/radius；`get_slot_marker(id)->Marker3D` 是实际位置真相，状态只存slot_id和quarter_turn。4地面槽可转0/90/180/270，4悬挂槽固定0，禁止重叠由3.3状态负责。
- ground_01=(-5.35,.16,-1.85)，02=(4.70,.16,-1.8)，03=(-5,.16,4.7)，04=(4.75,.16,4.8)，占地半径.45m，不占soil。
- hanging_01=(-2.5,2.27,-2.05)，02=(3.8,2.27,-2.05)，03=(-6.1,1.82,1.4)，**04最终=(-4.85,1.98,-2.95)**。均有可见实体支杆/短绳，04有斜撑；灯笼顶环归零、灯体下垂.65m，不能再将模型按底面贴挂点。

## 3.4 水与远景

- `get_water_surface()`：WaterSurface，180×180m水平XZ、+Y法线、y=-.25。起始材质仅静态，3.4接管material_override。
- 水世界XZ半径22..35m透明淡出接背景；普通180m不透明水会把俯瞰远景遮满，已修。3.4已同步blend_mix与此fade，不用depth_prepass_alpha硬截透明边。
- `get_backdrop_material()` 返回ShaderMaterial，`atmosphere_tint` 默认白；3.4已同步夜间变色。背景曲面半径65、上下沿20/-50，192三角，横向镜像采样、repeat_disable防边界回卷；无需去修改生成原画。
- 灯笼本身无发光烘焙，局部光挂到已定义真实槽，顶环下.22m起点可由3.4调。
