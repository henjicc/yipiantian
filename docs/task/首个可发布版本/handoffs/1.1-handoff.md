## 最终决定与接口

- 2.1：稳定 ID `field_01`～`field_06`；作物 `greens`／`radish`；时长 1800／5400 秒。幼芽 `[0,.35)`、幼株 `[.35,1)`、成熟 1；无限种子，浇水一次加 .2 总进度，先结算再动作，空／成熟／已浇不再浇。成熟一田收获对应作物一篮并清空。
- 初始田况：01／02 空，03 青菜 1，04 青菜 .2，05 萝卜 .1，06 萝卜 .6，全部未浇、累计零，仅首次创建保存。后台／休眠／关闭继续生长；UTC 秒、回拨有效增量零且保留较新基准，异常前跳最多本轮成熟，不自动收获和多轮收益。
- 3.3：粗陶罐任意 3 篮，花盆青菜 5＋萝卜 3，灯笼青菜 10＋萝卜 6，累计不扣；每种一件，有限地面位置／挂点，占用互斥，移动可取消。工具与布置各自取消，不穿透相机和界面。
- 1.2：继续既定 A 工笔淡彩和本目录参考；真实 Godot 全景／聚焦对照，开发侧自主判断并修复后继续，不伪造用户反馈。院落／石桥／木船／水岸／远山／植被需实际制作，简单色块不能当成品。资产范围已明确，可按代表样片定制作路线后扩展。
- 3.4／4.1：昼夜仅表现，轻量环境声／操作声／背景音乐；失焦或最小化静音，恢复按设置继续。最小设置限总音量／音乐／音效、窗口／全屏、标准／低画质、景深开关及操作查看，持久化设置；无账号、多槽位或重置进度按钮。
- 4.2：测试机 Windows 10 Pro 19045、5900X、约 64 GB、RTX 4090；1080p 标准六田目标 60 fps，帧间隔 p95 ≤20 ms、p99 ≤33.4 ms，具体采样场景／内存／启动／后台口径见实施方案。不把高配实测冒称最低配置，4K60 是录制规格。
- 5.1／5.2／5.3：本轮本地可解压 Windows x86_64 包，不绑定商店。用户第 7 条明确暂缓商务授权调查与购买授权路线，停止这些调查，不阻塞研发及本地出包，不因此更换参考或重做合格素材；保留已有来源与真实贡献，不宣称商用权利已核验。最终由开发侧真实试玩、参考对照、交付用户可试玩包，用户签收尚未取得。
