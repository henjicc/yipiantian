# 4.1 成品界面与设置交接

## 当前状态

已完成。实施、隔离状态测试、原生 Vulkan 回归、普通发行程序独立检查与最终截图均已完成；所有本代理 Godot 进程已退出，GPU / 导入时隙已归还根代理。提交由根代理精确执行。

## 接入契约

- 正式入口直接读取并恢复农场，没有独立标题屏或强制教学。首档仍由 FarmStore 生成成熟田与空田，界面不创建另一份农场状态。
- `main.settings_store` 可在入树前注入 `SettingsStore.new(隔离目录)`。默认仅使用 `user://preferences/settings.json`，版本 1，与 FarmStore v2 完全独立。所有现有实例化主场景的测试均补了独立 preferences 目录；新夹具也必须同时注入 farm 与 settings。
- 六项偏好为 `master=0.8`、`music=0.7`、`effects=0.8`、`fullscreen=false`、`quality="standard"`、`dof_enabled=true`。音量仅接受有限 0..1 数值；窗口与景深为 bool；画质只有 standard / low。设置页不新增景深强度滑杆。
- `SettingsStore.load_settings()` 返回状态和副本；`save()` 先验证再暂存并校验、替换。坏件在明确保存时原样另存，未来版本拒绝覆盖，过期会话拒绝覆盖磁盘变化。失败不改变农场文件，也不伪报保存成功。
- 设置变化立即送入 `farm_audio.set_volumes`、`focus_detail.set_quality` / `set_depth_of_field`。低画质暂时关闭实际景深，保留用户开关；关闭景深仍使用焦点 LOD。
- `GameMenu.present()` / `dismiss()` 管理同一设置／操作／来源模态；dismiss 同时关闭子弹窗。Tab 和方向键焦点限制在当前页可见控件。模态打开与关闭清除旧指针手势；Esc / 右键先取消装饰预览，再关模态，再执行原农场返回。
- 退出依次处理设置与农场保存。设置失败提供重试或明确不保存选择；农场写入失败会关闭设置模态，露出原存档失败／恢复入口。存档失败页可见的重试／恢复／退出按钮具有显式 Tab 与方向键焦点环，避免键盘到达底层 HUD。
- 实际窗口最小值在 main `_ready` 用 `get_window().min_size = Vector2i(960,600)` 设置，未保留无效的 ProjectSettings min_width / min_height 项。窗口模式恢复时清除 borderless 标志，保留正常标题栏。
- 有效录制会话的设置目录由 main 跟随录制隔离目录注入；4.3 录制节点在设置应用后自行配置真正 4K 全屏。没有需要演示跳过的首次引导页。

## 界面与资源

左上为真实总篮数及两作物计数，右上为真实本地时钟及日／夜图标，下方为作物选择和播种／浇水／收获。当前工具有 ✓ 标记；农田状态、短反馈与保存状态使用小纸签，夜间也有足够对比。布置、完成、设置、返回和复位入口统一字体、纸色与描边，不覆盖院落主体。

字体为官方 Noto Serif CJK SC Regular 2.003，原始 OTF 与 SIL OFL 1.1 随资源保留。44,777 Unicode 映射覆盖当前全部 UI 文案，未复制 Windows 系统字体。来源、文件哈希和 imagegen 实际提示词见 `ArtSource/UI/README.md`。

青菜应用图标由 imagegen 生成并采用原 PNG；一个针对性清边候选未采用。原件在 32 / 48 / 128 像素及三种底色实渲未见彩边。六枚操作／时段图标直接编写 SVG。主题与界面由 Godot 真实控件绘制，没有整张概念 UI 覆盖。imagegen 未返回费用数字，未记为免费或虚构金额；本编号未生成 3D 模型。
