## 分工与最终行为

- [风动与前景](风动与前景-handoff.md)：分植物类型的根部约束顶点风动，原贴图和导入LOD保留；全景镜头两侧真实三维植物框景，仅前景虚化，聚焦／布置退让。低画质取消前景与景深，关闭景深偏好时取消虚化。每田16株视觉锚点，不改作物类型、阶段、收获单位或存档。
- [水面与远云](水面与远云-handoff.md)：细波法线、渐弱短碎光、青绿水深与有限近岸反射；云层独立移动，山村底图不漂移。反射只读取屏幕内不透明几何，不能等同完整物理平面反射；其柔化／淡出避免将局部缺失放大成醒目边缘。
- [院落生活与船](院落生活与船-handoff.md)：桌篮、双层竹筛、农具、系船桩与绳，原屋纸窗暖光和两盏局部廊灯；船及荷叶缓慢起伏，湿石与苔色。没有新增玩法或摆放槽。
- 主代理负责昼夜光线、接触阴影、窗灯信号、土壤材质与联合验证：太阳高度／方向随昼夜平滑变化，暖直射光与冷环境光分离，Filmic色调映射避免强光截白。纸窗亮度独立于可解锁灯笼，日间克制、夜间形成院落亮点。泥土增加小土块和不规则色层，湿土仍由原浇水状态决定。
