# 美术方向：卡通形体与中国画意

> 当前确定的是主图距离和微缩空间感，以及“更卡通、更圆润简洁”的修正。工笔 / 水墨的程度仍处于探索；本文件展示当前候选，不代替用户选择或 Godot 实景验收。

## 已选定的部分与继续探索的部分

保留 [主图](images/00-approved-overview.png) 的完整农场构图、斜向层次、可看清立面的建筑比例和温暖生活气息。[聚焦参考](images/01-field-focus.png) 只说明靠近田地后的观察距离，生成时尚未融入最新国画方向；不以它锁定近景材质，也不认为它与主图拥有完全一致的几何。

**当前视觉目标：圆润概括的三维形体 + 有控制的笔触、设色与留白。** 不继续增加摄影级叶脉和木纹，也不把卡通化理解成所有东西都光滑发亮。国画感优先从线条、色层和虚实取得，不给整个画面盖一层黄色旧纸或随机墨点。

参考提炼是针对本项目的设计判断，不是对传统画种的完整定义。尤其“工笔”并不等于省略细节；我们选择借鉴它的线条和设色，同时保留已确认的简洁游戏形体。原作及机构说明见 [参考来源](sources.md)。

## 三张全景对照

### A · 工笔淡彩取向

![A 工笔淡彩取向](images/style-trials/ink-a-gongbi-overview.png)

目前最接近原主图，色彩和细节更柔和，轮廓比较清晰。国画改变较轻，仍偏温润三维微缩；不能仅因提示词写了工笔就声称已经充分体现工笔笔法。

### B · 彩墨写意取向

![B 彩墨写意取向](images/style-trials/ink-b-wash-overview.png)

远景墨色、稀疏层次与水面留白更明显，色彩更克制。需要留意种植状态、夜间和阴影中的对比度；不能把成熟标记也淡到看不清。

### C · 青绿与淡墨结合

![C 青绿与淡墨结合](images/style-trials/ink-c-green-hybrid-overview.png)

保留较多三维体积和暖色生活气息，背景增加淡墨层次。**开发侧建议先比较 C 的整体与下方 A 作物的材质**，兼顾画意和操作清晰度；这是建议，尚未被用户采用。此图主要实际输入为花卉设色与淡墨山水，不声称直接临摹《千里江山图》。

三张的构图大体保持一致，但仍有树木、路径与道具差异；它们是风格概念图，不是同一引擎场景的材质实验。看中的元素可以组合，后续用真实场景统一验证。

## 作物近看时的区别

### 作物 A · 淡彩与细线

![作物 A 淡彩与细线](images/style-trials/greens-a-light-colour.png)

圆润叶形上增加有限轮廓线与色彩层次，保留立体感。当前局部色斑仍可能偏密，做材质时应在实际显示大小下删减，不照抄每一处纸感纹理。

### 作物 B · 墨色与留白

![作物 B 墨色与留白](images/style-trials/greens-b-ink-wash.png)

墨色浓淡和干笔边缘更显著，也更接近二维笔触。白色笔触断口只是风格表现，**不能当作叶片破洞或缺失几何**。这类图用于材质方向比较；三维重建应另用清楚连续的结构图，不直接期待 Tripo 自动区分笔触和几何。

## 跨资产共用的约束

| 维度 | 采用方向 | 检查方式 |
|---|---|---|
| 轮廓 | 略夸张、圆润、成组概括，叶片较宽，屋瓦与石头分组 | 缩到游戏实际大小仍能分清种类，避免每件物体都变成同样的圆球 |
| 线条 | 深绿、茶褐或墨灰的选择性轮廓，疏密有别 | 不给每个三角形描线，不让线比作物状态还醒目 |
| 设色 | 米白、墨灰、赭木、暖土、苔绿与青绿，小面积暖灯 | 阴影不死黑，成熟作物与土地分离；不机械复制老画黄化底色 |
| 表面 | 大色层与少量笔触；低高光，保留陶、木、叶、瓦的区别 | 不出现摄影噪点、密集木纹、裂墙、叶脉网格或统一塑料光泽 |
| 空间 | 操作区明确，水面与远景疏淡，近中远层次清楚 | 聚焦和转动之后仍知道田在哪里；留白不吞掉可操作地面 |
| 光照 | 主场景保留暖意，单体结构用中性光 | 将材质底色与夕阳 / 夜灯分开，避免永久烘进方向性阴影 |

## 生成与引擎验证方法

后续提示词分别说明输入图的职责：主图管镜头构图，已选风格图管笔触和设色，结构图管部件与连接。不要把几张职责不明的图混在一起，也不要把尚未选定的 A / B / C 同时作为同一资产的风格标准。

先做一块田、一种作物、少量建筑材质，在同一场景内比较全景、聚焦与小幅转动。检查笔触跟随物体是否自然、细线是否闪烁、昼夜下是否易读；这些尚未实测。具体 Godot 材质或描边方法进入实现时查匹配版本官方文档，不在此预定某个 Shader 能自动达到概念图。

生成记录保留实际提示词和参考关系，但随机生成不能保证同图复现。图像工具与 Tripo 是两种不同环节；本次未提交 Tripo 请求，未产生游戏模型。详细交接原则仍见 [资产工作流](../asset-workflow.md)。
