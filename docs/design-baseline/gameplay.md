# 玩法与操作基线

> 2026-09-17 · v0.5。用户最新明确要求一块田内分小格、可混种、逐格播种和收获，取代 v0.4 的整田操作。每田 4×4 格是开发侧采用的具体尺寸；两种作物、时间与解锁数值继续沿用首版。历史整田版本的验收仅适用于其代码基线。

## 核心体验

一座可以俯瞰、靠近和照料的江南小农场。远看是一幅有生活气息的微缩田园，靠近能看到作物长大；几次简单操作就能完成照料，过一阵回来有收获，再用少量装饰留下自己的痕迹。

主循环：**全景看田 → 点击田块靠近 → 选择小格 → 选作物并播种 → 可选浇水 → 现实时间生长 → 逐格收获 → 点缀院落 → 返回观赏**。离线不会失败，不需要每日打卡，也不强迫玩家守着倒计时。

## 场地与种植单位

- 首个完整试玩版按 **6 块田**组织，以主参考图的观察距离和场景层次为目标。田块之间留道路，房屋在后方、水岸在侧前方；大小与间距在体块中调整，不能把六块田扩成挤满屏幕的六个按钮。
- 每块田划为 **4×4 个小格**，全场 96 格；每格独立保存一种作物的生长和浇水状态，一格显示一株，允许同田混种。格间以细土垄分隔，选中格单独强调。
- 六块大田保留 `field_01`～`field_06`，格子按行排列为 `cell_01`～`cell_16`；身份不依赖模型、位置和当前显示阶段。拖拽刷种与自由划地仍不在范围内。
- 原型先用两块田与一种作物验证全景、聚焦和种植；通过后扩到六块田与两种作物，视觉距离始终以选定主图为参照。

## 作物与生长

| 作物 | 外观区别 | 初始调参值 | 本版用途 |
|---|---|---|---|
| 青菜 | 淡绿短叶柄、宽圆叶片、开放莲座；不画成球形卷心菜 | 30 分钟成熟 | 较短回访节奏，快速体验照料和收获 |
| 白萝卜 | 有轮廓区别的绿叶、露出少量白色根肩；主体埋入土里 | 90 分钟成熟 | 较长回访节奏与另一种田园外观 |

种子无限，不设买卖、价格或种子背包。聚焦后选小格，再从种子选项选择青菜或白萝卜，点“播种”操作该空格。收获一个成熟小格记为对应作物 **1 篮**，然后该格回到空地，相邻格不受影响。两种作物没有售价差异，以外观与等待节奏区分。

三个可见生长阶段：幼芽（有效进度 0%～不足 35%）、幼株（35%～不足 100%）、成熟（100%）。阶段切换以同一根部和植株布置为基准，不用把一个成熟模型单纯缩小来冒充所有阶段。青菜与萝卜各有自己的阶段轮廓。

### 浇水

每轮种植可浇水一次，增加该作物总生长时长 **20% 的有效进度**；青菜相当于 6 分钟，萝卜相当于 18 分钟。先按旧状态结算到操作时刻，再增加进度并限制在成熟以内；重复操作不叠加。成熟、空田和已浇水田不接受本次浇水。

浇水用一次短暂水花、土色变化和已照料状态反馈。没有浇水的作物照常成熟；不加入水分蒸发、肥料、枯萎和疾病。这是轻量照料奖励，不是真实农业模拟。

## 首次进入与回访

新农场的 01／02 田全空；03～06 田的 `cell_06` 分别为成熟青菜、青菜 20%、萝卜 10%、萝卜 60%，其余小格为空。均未浇水、累计收获为零，保留原先四份初始作物而不放大收益。此初始状态只在首次建立农场时创建并保存，不能在读档、重启或切换相机后再次发放。

成熟田用可辨识的饱满轮廓与低强度状态标记提示，不持续闪烁。全景主要帮助寻找哪块田值得靠近；具体操作在聚焦视图进行。只保留必要工具标签、作物选项、收获记录和“全景”入口，不制作强制教学弹窗或密集说明文字。

## 镜头与输入

| 输入 / 状态 | 结果 |
|---|---|
| 全景左键点田 | 仅选择并移动聚焦；这次点击不穿透播种、浇水或收获 |
| 聚焦时点击小格 | 只选中该格，不执行农事；没有选中格时农事按钮不可用 |
| 选中空格后选择作物，再点“播种” | 只播种该格；禁止覆盖已有作物 |
| 选中格后点“浇水 / 收获” | 条件满足时只操作该格；成功后保留选格，相邻格不变 |
| 点非当前田块 | 只切换聚焦对象；不在另一个田块上直接执行遗留工具动作 |
| 滚轮 | 围绕当前关注点适度缩放；不穿过作物、房屋或地面 |
| 中键拖动 | 小范围转动水平角和俯仰，保留可理解的斜向视角 |
| Shift + 中键拖动 | 小范围平移，限制在农场或当前田块附近 |
| 点击“全景” | 返回进入聚焦前的全景位置、角度和缩放；清除选格与操作状态 |
| 右键 | 清除当前选格或取消放置预览；无选格时返回全景 |
| Esc | 优先关闭弹窗、取消选格 / 放置；无操作待取消时回全景；全景下不直接退出游戏 |
| 视角复位入口 | 回到默认全景，供过度微调后找回构图；具体控件位置在 UI 设计时落实 |

相机使用同一场景的真实三维视角移动。初始可用约 0.6～0.9 秒柔和过渡试手感，角度、速度和缩放范围不从生成图反算为准确值。移动过程中不执行农事动作、不缓存按键补做；再次点击别的田时改为最新目标，不排队移动。返回全景也应可打断。

UI 拦截场景点击；有效点击需在同一目标内按下并释放，拖动与失焦取消未完成点击。相机微调不修改农场玩法数据，也不让背面、树冠和围栏遮挡变成无法退出的视角。必要时限制角度或调整场景摆放，先不预建复杂遮挡框架。

## 收获后的轻量目标

完整试玩版用三项一次性装饰解锁提供回访目标，不设置消耗货币、任务刷新或倒计时：

| 装饰 | 解锁条件（累计，不扣除收获） | 摆放方式 |
|---|---|---|
| 粗陶罐 | 任意作物合计收获 3 篮 | 在预设院落装饰位置中选择一个 |
| 小花盆 | 青菜累计 5 篮、萝卜累计 3 篮 | 同上 |
| 小灯笼 | 青菜累计 10 篮、萝卜累计 6 篮 | 选择预设挂点 |

每种一个，允许在对应位置之间移动；占用的位置不能叠放，取消不会改变原位置。解锁只发生一次，记录与摆放位置随农场保存。门槛是调参起点；若等待过长或只是机械重复，先调节奏，不用新增经济系统补救。

摆放由独立的“布置”入口进入，暂不把它挤进三种农事工具。聚焦中进入布置时先返回全景并清除农事工具；退出布置回普通全景。已解锁物件只在允许的位置预览并确认，未解锁的不进入放置状态。这一层在种植和镜头验证后制作，不阻塞首个原型；暂不做自由建造、拖地形或装饰商店。

## 现实时间与存档

生长以有效现实时间为准，UTC 时间戳用于持久化，本地时钟只控制时间显示和昼夜表现。关闭、失焦、休眠和后台低帧率不暂停生长；明确暂停菜单尚不在范围内。离线直接结算到成熟上限，不自动收获或产生多轮收益。

回拨不倒退作物，保留较新的结算基准；时钟追上后继续，不能重复结算。异常前跳最多令本轮成熟。保存失败、格式损坏和不支持版本要区分，并保留旧有效数据；成功动作后及时保存，不只依赖正常退出。具体实现与边界验证遵循 [模拟规则](../../rules/farm-simulation.md)。

v3 保存：版本、田块与小格身份、每格作物类型、有效进度、最后结算时间、本轮浇水标记、按作物累计收获、装饰解锁与位置。视觉植株从小格状态重建。v1／v2 整田存档迁移到原田的 `cell_06`，保留作物状态、累计收获和装饰，其余格为空；迁移前留存不可变原件。相机微调不跨启动保存。测试使用隔离存档及可控时间，不改系统时钟。

## 进入详细计划时的拆分依据

1. **先验证空间操作**：灰盒农场、全景与聚焦、微调与返回；用户能辨认自己正在操作哪块田。
2. **完成种植闭环**：一种作物、整田动作、计时、离线与存档；恢复和重复输入不会重复产出。
3. **固定实际引擎风格**：一块田、作物阶段、一处建筑和少量材质，在全景与聚焦距离检查“卡通偏写实”。
4. **扩为完整试玩版**：六田、两作物、昼夜与三项装饰目标，导出 Windows 程序试玩。

详细执行顺序与状态以 [任务总览](../task/首个可发布版本/00-任务总览.md) 为准，整个计划已授权启动。暂缓季节、天气影响生长、真实日照计算、动物、角色、加工交易、联机与桌面壁纸宿主。主图里的船、桥、远村也不自动承诺对应玩法。
