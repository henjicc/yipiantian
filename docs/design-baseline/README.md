## 当前决定

- **用户已选定**下面主图的观察距离、整体构图与微缩田园感觉，保留全景点击田块后平滑聚焦、允许微调视角的方向。
- **用户已确认风格**：A 工笔淡彩全景 + A 淡彩青菜，圆润简洁的卡通形体、选择性细线、淡彩笔触与自然哑光质感。两张固定图和复用模板见 [风格基准 v1](style-guide.md)。
- **历史探索**：B 彩墨、C 青绿淡墨与墨色青菜保留作对照；此前 C + A 的开发侧建议已被用户选择取代。
- **现役玩法**：六田、每田4×4格、十二种作物；持种子悬停预览后点击播种，工具分类展开，保留三件累计解锁装饰。[玩法与操作](gameplay.md) 是早期基线；原 [1.1 交接](../task/首个可发布版本/handoffs/1.1-handoff.md) 的整田操作同属历史。
- **待选方案**：[动物行为与轻松玩法候选](动物行为与轻松玩法候选.md)（2026-09-18）。动物随机活动、鸡步行、邻里往来和后续创意仅供挑选，不代表已实现或整包批准。
- **后续完整目标**：用户要求按动物在前、玩法在后的顺序完整建设，目标顺序与完成标志见[完整目标清单](../task/动物与田园生活完整目标清单.md)。它取代上轮小样推进建议；本次只输出当前可运行版本和清单，未勾选项尚未实现。
