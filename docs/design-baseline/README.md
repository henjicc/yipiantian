## 当前决定

- **用户已选定**下面主图的观察距离、整体构图与微缩田园感觉，保留全景点击田块后平滑聚焦、允许微调视角的方向。
- **用户明确修正**：单体不能过于写实，需要更圆润简洁的卡通造型，同时保留自然材质感；最新希望进一步尝试中国工笔或水墨画的感觉。
- **仍在比较**：国画元素的具体比例。新生成的工笔淡彩、彩墨写意和青绿淡墨都是候选，不能写成用户已经选定。
- **由开发侧拟定**：整田操作、六块田、两种作物和轻量装饰目标，作为玩法方案进入后续计划；具体数值可经试玩修订，不等同于已实现。
