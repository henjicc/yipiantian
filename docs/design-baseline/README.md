# 我有一片田 · 制作基准包

> 2026-09-17 · 初期方案。供后续制定详细开发计划使用；已有一个 Tripo 成熟青菜测试模型，尚未进入正式游戏，没有新增玩法实现。

## 当前决定

- **用户已选定**下面主图的观察距离、整体构图与微缩田园感觉，保留全景点击田块后平滑聚焦、允许微调视角的方向。
- **用户已确认风格**：A 工笔淡彩全景 + A 淡彩青菜，圆润简洁的卡通形体、选择性细线、淡彩笔触与自然哑光质感。两张固定图和复用模板见 [风格基准 v1](style-guide.md)。
- **历史探索**：B 彩墨、C 青绿淡墨与墨色青菜保留作对照；此前 C + A 的开发侧建议已被用户选择取代。
- **由开发侧拟定**：整田操作、六块田、两种作物和轻量装饰目标，作为玩法方案进入后续计划；具体数值可经试玩修订，不等同于已实现。

![已选定的距离、构图与整体感觉](images/00-approved-overview.png)

这张图负责构图和氛围。用户后续对“卡通化、国画感”的修正优先于图中的微小写实纹理；不再根据单体放大图追加叶脉、破损和摄影级细节。远景、船桥和作物数量也不自动成为玩法清单。

当前已固定图片风格，补齐首批资产制作单位、交接与验收顺序，并完成一个 Tripo 青菜小样及 Blender 检查。该样本实际面数超过试验目标，需进一步处理；完整记录保存在本地 `制作留档/`，验证摘要见 [资产工作流](../asset-workflow.md)。下一阶段按 [资产准备清单](asset-list.md) 完成模型适配和两田原型，在同一三维场景验证全景 / 聚焦下的轮廓、材质与可读性。本包仍是制作基础，没有提前批量生成模型或实现玩法。
