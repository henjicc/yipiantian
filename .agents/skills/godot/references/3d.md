# 3D Essentials Reference

**Verified 2026-06-19** against Godot 4.7. Godot 4 added the `3D` suffix to the spatial nodes (`Spatial` is now `Node3D`, `Camera` is `Camera3D`) and renamed `SpatialMaterial` to `StandardMaterial3D`. 4.7 adds `AreaLight3D`, nearest-neighbor 3D scaling for retro looks, HDR output, and a dedicated MeshLibrary editor. Re-verify if a newer minor changes them.

The 2D subsystems documented elsewhere have 3D twins with the same API and a `3D` suffix. This file covers what is unique to 3D scene setup; for the shared systems see the inline 3D notes in [physics.md](physics.md), [navigation.md](navigation.md), [particles.md](particles.md), and [animation.md](animation.md).

## 2D to 3D mental map

| 2D | 3D |
|---|---|
| `Node2D` | `Node3D` |
| `Vector2` / `Vector2i` | `Vector3` / `Vector3i` |
| `CharacterBody2D`, `Area2D`, `RayCast2D` | `CharacterBody3D`, `Area3D`, `RayCast3D` |
| `Sprite2D` | `MeshInstance3D` (or `Sprite3D` for billboards) |
| `Camera2D` | `Camera3D` |
| `SpatialMaterial` (3.x) | `StandardMaterial3D` |

## Coordinate system

Right-handed, **Y is up**, and **-Z is forward** (a camera looks down its local -Z). 1 unit = 1 meter, which keeps physics realistic. Keep models scaled to meters.

## Node3D transform

```gdscript
position            # Vector3, local
rotation            # Vector3 in radians; rotation_degrees for degrees
scale               # Vector3
global_position     # world-space position
global_transform    # Transform3D (basis + origin) in world space
basis               # the 3x3 rotation/scale; basis.z is the local forward axis
look_at(target, Vector3.UP)        # face a world point
rotate_y(angle)  translate(offset)  # relative moves
```
Prefer `Transform3D`/`basis` math over Euler angles when composing rotations to avoid gimbal issues.

## Camera3D

```gdscript
@onready var cam: Camera3D = $Camera3D

cam.make_current()                 # activate this camera (or set `current = true`)
cam.fov = 70.0                     # perspective field of view
cam.projection = Camera3D.PROJECTION_ORTHOGONAL   # ortho for isometric/strategy
var ray := cam.project_ray_normal(get_viewport().get_mouse_position())  # mouse picking
```

## Lighting and environment

- Lights: `DirectionalLight3D` (sun/outdoor), `OmniLight3D` (point), `SpotLight3D` (cone). Enable `shadow_enabled` per light.
- `AreaLight3D` (Godot 4.7) is a rectangular area light (`Light3D` subclass) for soft shadows, neon tubes, and screen-glow looks. Key props: `area_size` (Vector2), `area_range`, `area_attenuation`, `area_texture`.
- `WorldEnvironment` holds an `Environment` resource controlling the sky/background, ambient light, tonemapping, glow, fog, SSAO, and SSR. One per scene.
- A `DirectionalLight3D` plus a `WorldEnvironment` with a procedural sky is the minimal lit scene.

## Meshes and materials

```gdscript
# A mesh + material in code
var mi := MeshInstance3D.new()
mi.mesh = BoxMesh.new()
var mat := StandardMaterial3D.new()
mat.albedo_color = Color(0.8, 0.2, 0.2)
mat.metallic = 0.0
mat.roughness = 0.6
mat.emission_enabled = true
mat.emission = Color.ORANGE
mi.material_override = mat
add_child(mi)
```
`StandardMaterial3D` is PBR (albedo, metallic, roughness, normal, emission, AO). Pack metallic/roughness/AO into one ORM texture for performance. Use `material_override` to swap a whole mesh's material, or set surface materials per slot.

## Importing models

Prefer **glTF** (`.glb`/`.gltf`) for imported models; it is Godot's best-supported format. Drop the file in the project and Godot imports it as a scene you instance. Configure import options (collisions, LODs, materials) in the Import dock.

## Prototyping geometry

- **CSG** nodes (`CSGBox3D`, `CSGCylinder3D`, `CSGCombiner3D`, with union/subtraction/intersection) block out levels without external modeling. They are heavier at runtime; replace with imported meshes for shipping. 4.7 adds angle-based CSG autosmoothing.
- **GridMap** is the 3D tilemap: paint instances from a `MeshLibrary` (built from a scene of meshes) onto a 3D grid, the analogue of TileMapLayer. 4.7 adds a dedicated MeshLibrary editor (like the TileSet editor) so you no longer round-trip through a scene to edit tiles.

## Renderer

Pick per target: **Forward+** (desktop, full features), **Mobile** (mobile/lighter desktop), **Compatibility** (GL, web and old hardware). Set it in Project Settings; it changes which rendering features are available. Direct3D 12 is the default driver for new Windows projects since 4.6, and Jolt is the default 3D physics engine since 4.6 (see [physics.md](physics.md)).

Godot 4.7 adds **HDR output** (Windows, macOS, iOS, visionOS, Linux/Wayland), an opt-in feature for HDR displays. For crisp retro 3D, set the viewport's 3D scaling to nearest-neighbor:
```gdscript
get_viewport().scaling_3d_mode = Viewport.SCALING_3D_MODE_NEAREST   # 4.7; project setting rendering/scaling_3d/mode
```
